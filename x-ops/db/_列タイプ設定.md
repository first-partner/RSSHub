# CSVインポート後の列タイプ設定

Notionへのインポート直後、すべての列は「テキスト」になります。以下に従って手で変更してください。
（この作業は最初の1回だけです）

## DB-A 投稿カレンダー

| 列 | タイプ | 選択肢 |
|---|---|---|
| タイトル | Title | |
| ステータス | Status | ネタ / 作成中 / レビュー待ち / 修正中 / 承認済 / 予約済 / 投稿済 / 見送り / 削除 |
| 投稿予定日時 | Date（時刻ON） | |
| 種別 | Select | 単発ポスト / スレッド / 引用リポスト（交流） / 𝕏記事引用 / 画像 / 動画 / アンケート |
| コンテンツピラー | Select | ①常識破壊 / ②営業×AI / ③パパの哀愁 / ④生存戦略 |
| フック型 | Select | 疑問形 / 数字 / 常識破壊 / 問題提示 / 反語的疑問 |
| CTA型 | Select | 質問形 / 共感形 / 行動形 |
| 本文 | Text | |
| リンク先URL / 投稿URL | URL | |
| 担当 / レビュー担当 / 承認者 | Person | |
| 承認日 | Date | |
| 断定表現チェック / 一次情報チェック / 特定情報チェック | Select（OK / NG / 要確認） | 03_NG禁止事項 のチェックリストに対応 |
| インプレッション 〜 フォロー増 | Number | |
| ネタ元 | Relation → DB-B | |

**追加する数式列**
- `エンゲージメント率` = `prop("エンゲージメント数") / prop("インプレッション")`（表示形式: パーセント）

**追加するビュー**
- カレンダー（投稿予定日時）／ ボード（ステータス）／ テーブル「今週」（投稿予定日時が今週）／ テーブル「実績」（ステータス = 投稿済、インプレッション降順）

## DB-C 参考アカウント

| 列 | タイプ | 選択肢 |
|---|---|---|
| アカウント名 | Title | |
| URL | URL | |
| カテゴリ | Select | PPC直系 / 同ペルソナ / ベンチマーク（運用巧者） / ベンチマーク（バズ率） / 隣接業界 / 𝕏運用ノウハウ / 大型（導線のみ見る） |
| 採否 | Status | 提案中 / 採用 / 保留 / 不採用 |
| 追跡優先度 | Select | S（毎週見る・毎日絡む） / A（隔週） / B（月次） / C（四半期・導線のみ） |
| フォロワー数 / 投稿頻度（本/週） | Number | |
| フォロワー数の記録日 / 調査日 / 次回調査予定 | Date | |
| 主な投稿形式 | Multi-select | テキストのみ / テキスト+画像1枚 / 画像4枚 / スレッド / 動画 / 引用 / アンケート |
| 主な投稿時間帯 | Multi-select | 朝 / 昼 / 夕 / 夜 / 深夜 |
| トーン | Select | 丁寧 / フランク / 専門的 / ユーモア / 挑発的 |
| 調査担当 | Person | |

**追加するビュー**: ボード（カテゴリ別）／ テーブル「今月調べる」（次回調査予定 ≦ 今月末）
