# 3-3 LINE構築手順（プロラインフリー版）

## 0. 私にできること・できないこと

| | |
|---|---|
| ❌ **できない** | LINE公式アカウント／プロラインフリーの**アカウント作成そのもの** |
| ✅ できる | 手順書、設定内容の設計、シナリオ・タグ・流入経路の設計、**配信原稿の完成品** |

アカウント作成には **LINEビジネスIDの本人認証（メール／電話番号／SMS）** が必要で、
これはご本人にしかできません。認証情報をこちらで扱うべきでもありません。

そこで、**手を動かす部分以外はすべて用意しました。** 下の手順どおりに進めれば、
考えることなく作れます。**原稿は5通とも完成品**なので、コピペで入ります（4章）。

---

## 1. 構築の順序（この順で進める）

```
① プロラインフリーに登録
      ↓
② 左メニュー「設定 → 初期設定(Messaging API)」→「アカウント設定を始める！」
      ↓
③ 「LINE公式アカウントを持っていますか？」→ 持っていない を選ぶ
      ↓  （ナビの中でLINE公式アカウントの作成に誘導されます）
④ LINEビジネスIDを作成 → LINE公式アカウントを開設
      ↓
⑤ Messaging APIを有効化し、プロラインと接続
      ↓
⑥ 接続確認（プロラインの「連携チェック」で確認できます）
      ↓
⑦ 挨拶メッセージ・シナリオ・タグ・流入経路・リッチメニューを設定 ← 設計は本書3章
```

所要 **1〜1.5時間**。詰まるとしたら⑤のMessaging API有効化です。
プロラインの公式マニュアルに画面つきの手順があるので、そこを見ながら進めてください。

### ⚠️ 先に確認してほしいこと

> **LINE公式アカウントは、Messaging API連携できるツールを1つしか持てません。**
> すでに別のツール（Lステップ等）と連携したLINE公式アカウントをお持ちの場合、
> プロラインと繋いだ時点で**既存の連携が解除されます。**

現状LINE公式は未導入と伺っているので問題ないはずですが、
過去に作ったアカウントが残っていないか、一度だけ確認してください。

## 2. プラン判断（★先に決めておく）

### LINE公式アカウント側（LINE社への支払い）

| プラン | 月額 | 配信可能通数 |
|---|---|---|
| コミュニケーション | **0円** | **月200通** |
| ライト | 5,000円 | 5,000通 |
| スタンダード | 15,000円 | 30,000通〜 |

**通数は「配信数 × 人数」で数えます。** ステップ配信も同じです。

### つまり、無料枠はすぐ埋まります

| ステップ本数 | 無料枠200通で配信できる人数 |
|---|---|
| 5通 | **40人まで** |
| 4通 | 50人まで |
| 3通 | 66人まで |

目標は **LINE登録 週10〜15人 = 月40〜60人**。
つまり **目標を達成した瞬間に無料枠を超えます。**

### 判断

> **ライトプラン（5,000円/月）を最初から織り込んでください。**
>
> 60万円の商材で月5,000円は、ケチるところではありません。
> 教材が1件売れれば10年分です。
>
> ただし切り替えは登録が増えてからで十分です。
> **運用ルール: 累計登録が30人を超えたらライトプランに切り替える。**

### プロラインフリー側（ツールへの支払い）

| プラン | 月額 | 制約 |
|---|---|---|
| **フリー** | **0円** | ステップ配信は10個まで。今回は5通1本なので**十分** |
| プロ | 9,680円 | |
| ゴールド | 29,700円 | |

**フリープランで始めてください。** 現状の規模で有料にする理由はありません。

> ※ 料金・通数は改定されることがあります（2026年10月に追加メッセージ料金の改定予定あり）。
> 契約時に必ず公式ページで最新を確認してください。

## 3. プロラインフリー側の設定設計

### 3-1. 流入経路（登録URLを分ける）

プロラインは**流入経路ごとに別のURLを発行**でき、経路別に集計できます。
フリープランでも使えます。**最初から分けてください。後から遡れません。**

| 経路名 | どこに貼るか |
|---|---|
| `X_固定ポスト` | 𝕏のプロフィール固定ポスト |
| `X_記事` | 𝕏記事の末尾CTA ← **主力** |
| `X_プロフリンク` | プロフィールのリンク欄 |
| `X_通常ポスト` | 通常ポストのツリー最終 |
| `その他` | 予備 |

これで「𝕏記事から来た人」と「固定ポストから来た人」の登録数が分かれて見えます。
どちらを強化すべきかが数字で決まります。

### 3-2. タグ設計

| タグ | 付けるタイミング |
|---|---|
| `ステップ完走` | 5通目まで到達 |
| `Zoom申込` | 申込フォーム送信 |
| `Zoom参加` | 実施後に手動 |
| `Zoom不参加` | 無断キャンセル |
| `教材購入` | 決済後 |
| `断り_金額` / `断り_時間` / `断り_自信` / `断り_信頼` | **翌日フォローで聞いた理由** |

> **最後の4つが一番大事です。** 3件貯まった時点で、次に直す場所が確定します（→ `08` 4章）。

### 3-3. リッチメニュー（3枠）

| 枠 | 内容 |
|---|---|
| 左 | **7ステップの資料をもう一度見る** |
| 中 | **無料Zoomに申し込む** |
| 右 | スナの𝕏へ |

作り込まなくて大丈夫です。テキストだけの簡素なもので機能します。

### 3-4. 配信スケジュール

| 通 | タイミング |
|---|---|
| 1 | 登録直後（挨拶メッセージとして設定） |
| 2 | 登録の翌日 20:00 |
| 3 | 3日目 20:00 |
| 4 | 5日目 20:00 |
| 5 | 7日目 20:00 |

夜20時はスナの「実績・ロジック」枠と同じ時間帯です。生活リズムを揃えます。

## 4. 配信原稿（完成品・そのままコピペ）

> **【】で囲んだ箇所だけ、ご自身で埋めてください。** それ以外は手を入れなくて大丈夫です。

### 1通目｜登録直後（挨拶メッセージ）

```
登録ありがとうございます。スナです。

「毎日2時間で月120万にしたAI×広告の7ステップ」
こちらからどうぞ。
▼
【資料URL】

先に言っておきます。

この資料に、具体的な手順は書いていません。
クライアントとの契約上、出せない部分があるからです。

書いてあるのは「全体の地図」です。
どこを通るかは分かるけど、道の歩き方までは書いていない。

それでも、地図があるのとないのとでは全然違います。
僕は5年間、地図を持たずに歩いて、月2万が天井でした。

これから7日間、
・なんで営業マンがAI×広告に向いてるのか
・僕が5年間なにを間違えてたのか
を送ります。

不要ならいつでもブロックしてください。
それで僕が何か言うことはありません。

知らんけど。
```

### 2通目｜翌日20:00「なんで営業マンなんか」

```
スナです。

昨日の資料、目は通せましたか。

今日は「なんで営業マンなんか」という話をします。

僕は上場企業の営業です。
1日11時間拘束、外回り、接待、報告書。
副業に使える時間なんてない。

でも、AI×広告をやってみて分かったことがあります。

営業でやってることと、ほぼ同じでした。

・誰に売るか決める（ターゲット選定）
・その人が何に困ってるか考える（ヒアリング）
・刺さる言い方を探す（トーク）
・数字を見て打ち手を変える（PDCA）

順番も考え方も、営業そのものです。
違うのは、相手が人間じゃなくて画面ってだけ。

だから営業マンは有利です。
ゼロから商売を覚える人とは、スタート地点が違う。

僕がAIに何を任せてるかというと、
この「考える」以外の全部です。
文章を書く、案を出す、整える。
そこは部下にやらせて、自分は決めることだけやる。

ムチ打つ相手がおるって、ええもんですよ。

明日は、僕が5年間なにを間違えてたのかを書きます。
正直、あんまり書きたくない話です。
```

### 3通目｜3日目20:00「5年間、月2万が天井だった」

```
スナです。

今日は、あんまり言いたくない話をします。

僕、副業を始めて最初の5年間、月2万が天井でした。

Webライターをやってました。
1日5時間。土日も削って。
時給にすると133円です。

コンビニでバイトしたほうが稼げる。
それを5年やってました。

何が間違ってたか。

「好きなこと」で選んでたんです。
文章を書くのが苦じゃなかったから。

でも市場は、僕が何を好きかなんて関係ない。
需要があるところにしか金は流れない。

2025年の12月に、そこを切り替えました。
好きなことじゃなくて、ニーズが高いところへ。

初月2万、2ヶ月目60万、3ヶ月目80万、4ヶ月目120万。

作業時間は5時間から2時間に減ってます。
時給133円が、1.3万円になった。

やってることが変わっただけです。
僕が急に優秀になったわけじゃない。

だから思うんです。
5年間しんどかった人ほど、切り替えたら早い。
続ける力は、もう持ってるので。

明日は少し毛色の違う話をします。
```

### 4通目｜5日目20:00「僕以外の人の話」★最重要

```
スナです。

今日は、僕以外の人の話をします。

資料を読んで「で、結局どうやるん」と思った方が多いと思います。
当然です。地図しか渡してないので。

その「どうやるん」を相談できる場を作ってます。
無料のZoomです。

ただ、対応するのは僕じゃありません。
【実施者のお名前】さんという方にお願いしています。

なんで僕がやらないのか。
正直に言うと、本業が11時間拘束で、平日の日中に時間が取れないからです。
中途半端に自分でやるより、ちゃんと時間の取れる人に任せたほうがいい。

で、なんで【実施者のお名前】さんなのか。

【★ここに関係性のエピソードを1つ。実績ではなく、あなたが信頼している理由を。
　例：僕が最初につまずいて動けなくなったとき、
　　　答えを教えずに「どこで詰まってる？」って聞いてくれた人です。
　　　あれで自分の頭で考えられるようになった。】

実績を並べることもできますけど、
たぶんそれはあんまり意味がない。

大事なのは、この人が自分を舐めへんかどうかやと思うんです。
そこは、僕が保証します。

明日、Zoomの案内を送ります。
```

> **4通目の【★】が、この5通で最も重要な箇所です。**
> 同席ができない以上、ここが唯一の橋渡しになります。
> 実績の羅列は逆効果です。**関係性のエピソードを1つ**書いてください。

### 5通目｜7日目20:00「Zoomの案内」

```
スナです。

無料Zoomのご案内です。

▼申込はこちら
【申込フォームURL】

先に、これがどういう場なのか言っておきます。

このZoomは「教える場」ではありません。
あなたの状況を聞いて、どこで引っかかってるかを一緒に見る場です。

資料の7ステップのうち、今どこで止まってるのか。
それは知識の問題なのか、時間の問題なのか、それとも別か。
そこを整理するだけでも、だいぶ変わります。

それと、もうひとつ先に言っておきます。

話を聞いた上で、有料の教材のご案内をします。
合わないと思ったら、その場で断ってもらって大丈夫です。
断ったからといって、こちらから何かすることはありません。

「無料相談です」と言うといて後から売られるのは、
僕が一番嫌いなやつなので、先に言っときます。

申込のとき、ひとつだけ質問があります。

「今、副業で一番困っていることを1行で」

これを書いてもらえると、当日いきなりヒアリングから始めずに済みます。
1行で大丈夫です。

▼申込はこちら
【申込フォームURL】

知らんけど。
```

### 番外｜Zoom翌日フォロー（手動送信・★成約より情報が目的）

```
スナです。

昨日どうでした？
何か引っかかったとこあります？

正直に言ってもらって大丈夫です。
断ったからどうこう、みたいなのは一切ないので。

僕が知りたいのは、
どこが「無理やな」ってなったかだけです。
```

> 返ってきた内容から、`断り_金額` `断り_時間` `断り_自信` `断り_信頼` のタグを付けてください。
