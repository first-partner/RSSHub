# 3-3 LINE構築手順（プロラインフリー版）

## 0. 私にできること・できないこと

| | |
|---|---|
| ❌ **できない** | LINE公式アカウント／プロラインフリーの**アカウント作成そのもの** |
| ✅ できる | 手順書、設定内容の設計、シナリオ・タグ・流入経路の設計、**配信原稿の完成品** |

アカウント作成には **LINEビジネスIDの本人認証（メール／電話番号／SMS）** が必要で、
これはご本人にしかできません。認証情報をこちらで扱うべきでもありません。

そこで、**手を動かす部分以外はすべて用意しました。** 下の手順どおりに進めれば、
考えることなく作れます。**原稿は5通とも完成品**なので、コピペで入ります（4章）。

---

## 1. 構築の順序（この順で進める）

```
① プロラインフリーに登録
      ↓
② 左メニュー「設定 → 初期設定(Messaging API)」→「アカウント設定を始める！」
      ↓
③ 「LINE公式アカウントを持っていますか？」→ 持っていない を選ぶ
      ↓  （ナビの中でLINE公式アカウントの作成に誘導されます）
④ LINEビジネスIDを作成 → LINE公式アカウントを開設
      ↓
⑤ Messaging APIを有効化し、プロラインと接続
      ↓
⑥ 接続確認（プロラインの「連携チェック」で確認できます）
      ↓
⑦ 挨拶メッセージ・シナリオ・タグ・流入経路・リッチメニューを設定 ← 設計は本書3章
```

所要 **1〜1.5時間**。詰まるとしたら⑤のMessaging API有効化です。
プロラインの公式マニュアルに画面つきの手順があるので、そこを見ながら進めてください。

### ⚠️ 先に確認してほしいこと

> **LINE公式アカウントは、Messaging API連携できるツールを1つしか持てません。**
> すでに別のツール（Lステップ等）と連携したLINE公式アカウントをお持ちの場合、
> プロラインと繋いだ時点で**既存の連携が解除されます。**

現状LINE公式は未導入と伺っているので問題ないはずですが、
過去に作ったアカウントが残っていないか、一度だけ確認してください。

## 2. プラン判断（★先に決めておく）

### LINE公式アカウント側（LINE社への支払い）

| プラン | 月額 | 配信可能通数 |
|---|---|---|
| コミュニケーション | **0円** | **月200通** |
| ライト | 5,000円 | 5,000通 |
| スタンダード | 15,000円 | 30,000通〜 |

**通数は「配信数 × 人数」で数えます。** ステップ配信も同じです。

### つまり、無料枠はすぐ埋まります

| ステップ本数 | 無料枠200通で配信できる人数 |
|---|---|
| **6通（現行）** | **33人まで** |
| 5通 | 40人まで |
| 4通 | 50人まで |

目標は **LINE登録 週10〜15人 = 月40〜60人**。
つまり **目標を達成した瞬間に無料枠を超えます。**

### 判断

> **ライトプラン（5,000円/月）を最初から織り込んでください。**
>
> 60万円の商材で月5,000円は、ケチるところではありません。
> 教材が1件売れれば10年分です。
>
> ただし切り替えは登録が増えてからで十分です。
> **運用ルール: 累計登録が25人を超えたらライトプランに切り替える。**
> （ステップが6通になったため、無料枠200通でカバーできるのは33人です）

### プロラインフリー側（ツールへの支払い）

| プラン | 月額 | 制約 |
|---|---|---|
| **フリー** | **0円** | ステップ配信は10個まで。今回は5通1本なので**十分** |
| プロ | 9,680円 | |
| ゴールド | 29,700円 | |

**フリープランで始めてください。** 現状の規模で有料にする理由はありません。

> ※ 料金・通数は改定されることがあります（2026年10月に追加メッセージ料金の改定予定あり）。
> 契約時に必ず公式ページで最新を確認してください。

## 3. プロラインフリー側の設定設計

### 3-1. 流入経路（登録URLを分ける）

プロラインは**流入経路ごとに別のURLを発行**でき、経路別に集計できます。
フリープランでも使えます。**最初から分けてください。後から遡れません。**

| 経路名 | どこに貼るか |
|---|---|
| `X_固定ポスト` | 𝕏のプロフィール固定ポスト |
| `X_記事` | 𝕏記事の末尾CTA ← **主力** |
| `X_プロフリンク` | プロフィールのリンク欄 |
| `X_通常ポスト` | 通常ポストのツリー最終 |
| `その他` | 予備 |

これで「𝕏記事から来た人」と「固定ポストから来た人」の登録数が分かれて見えます。
どちらを強化すべきかが数字で決まります。

### 3-2. タグ設計

| タグ | 付けるタイミング |
|---|---|
| `ステップ完走` | 5通目まで到達 |
| `Zoom申込` | 申込フォーム送信 |
| `Zoom参加` | 実施後に手動 |
| `Zoom不参加` | 無断キャンセル |
| `教材購入` | 決済後 |
| `断り_金額` / `断り_時間` / `断り_自信` / `断り_信頼` | **翌日フォローで聞いた理由** |

> **最後の4つが一番大事です。** 3件貯まった時点で、次に直す場所が確定します（→ `08` 4章）。

### 3-3. リッチメニュー（3枠）

| 枠 | 内容 |
|---|---|
| 左 | **7ステップの資料をもう一度見る** |
| 中 | **無料Zoomに申し込む** |
| 右 | スナの𝕏へ |

作り込まなくて大丈夫です。テキストだけの簡素なもので機能します。

### 3-4. 配信スケジュール

| 通 | タイミング | 内容 |
|---|---|---|
| 1 | 登録直後（挨拶メッセージ） | 資料 +「全部は書けん」宣言 |
| 2 | 翌日 20:00 | なんで営業マンなんか |
| 3 | 3日目 20:00 | 5年間、月2万が天井やった |
| 4 | 5日目 20:00 | **LPの案内（動画セミナー）** |
| 5 | 6日目 20:00 | **Zoom実施者の紹介** |
| 6 | 8日目 20:00 | **ツール特典 + 紹介料の明示** |

> 順序の考え方：教育の本体はLP側の動画セミナーにあるので、**先にLPを見せる**。
> そのうえで「Zoomに出る人」を紹介し、最後に「僕経由で申し込む理由」を置きます。

夜20時はスナの「実績・ロジック」枠と同じ時間帯です。生活リズムを揃えます。

## 3-5. 投入順序（★ここを間違えると事故ります）

LINE公式の開設は完了済み。次はステップ配信ですが、**5通のうち2通はURLが要ります。**

| 通 | 必要なもの | 今すぐ投入できるか |
|---|---|---|
| 1 | **資料URL** | ❌ 資料待ち |
| 2 | なし | ✅ **今すぐ** |
| 3 | なし | ✅ **今すぐ** |
| 4 | LPのURL（判明済み） | ✅ **今すぐ** |
| 5 | 実施者のお名前＋紹介エピソード | △ 執筆すれば今日中 |
| 6 | ツール特典の受け渡し条件 + 紹介料の有無 | △ 決めれば今日中 |

### 今日やること

1. プロラインでシナリオを1本作る（**「停止」状態のまま**）
2. **2通目・3通目・4通目をそのままコピペで投入**（原稿は下の4章に完成品があります）
3. 5通目の【★紹介エピソード】と、6通目の【★特典条件】を書いて投入（30分）
4. タグ6種＋流入経路5本を設定（3章）
5. リッチメニューを作る（3章）

### まだやらないこと

> **🚫 𝕏記事の末尾CTAを LINE登録 に差し替えるのは、5通すべて揃ってからです。**
>
> 先に差し替えると、登録した人に渡すものが何もない状態になります。
> **最初の登録者が一番大事な人**なので、ここは焦らないでください。
>
> 同じ理由で、**シナリオは全部揃うまで「停止」のまま**にしておいてください。

### 残りの2通を埋める順序

```
① 7ステップ資料を作る（→ 10_7ステップ資料ドラフト.md に穴埋め式のドラフトあり / 約1時間）
      ↓ プロラインの「コンテンツページ」で作るとURLが自動で発行されます
② そのURLを1通目に貼る
      ↓
③ Zoom申込フォームを作る（事前質問欄を1つ入れる）
      ↓
④ そのURLを5通目に貼る
      ↓
⑤ 自分のスマホでテスト登録 → 5通すべて届くか確認
      ↓
⑥ シナリオを「稼働」に変更
      ↓
⑦ ここで初めて 𝕏記事のCTAを差し替える
```

> 発生しないなら、その旨を書いてください。それはそれで強い材料になります。
