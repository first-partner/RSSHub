# 2-2 トーン & マナー

> 「誰が喋っているか」を全投稿で一定に保つためのページ。担当者が変わっても声が変わらないようにする。

## キャラクター定義

| 項目 | 内容 |
|---|---|
| 人格の設定 | 【要記入】（例: 「業界5年目、後輩に教えるのが好きな担当者」） |
| 年齢感 | 【要記入】 |
| 距離感 | 敬語ベース / ため口混じり / 完全フランク ← 【選択】 |
| 一人称 | 【要記入】 |
| 二人称 | 「みなさん」/「あなた」/ 使わない ← 【選択】 |

## 3つの形容詞

このアカウントは **【要記入】・【要記入】・【要記入】** である。
逆に、**【要記入】ではない**。

## 語尾・表現の指針

| OK | NG |
|---|---|
| ですね / します / と思います | 〜っす / 〜だぜ |
| 具体的な数字を出す | 「めっちゃ」「超」などの誇張だけの強調 |
| 一次情報・自社の経験を語る | 出典のない伝聞・断定 |
| 失敗も書く | 成功だけを並べる |

## 絵文字

- 使用可: 【要記入】（例: 🙌 ✅ 📌 →）
- 使用不可: 顔文字の連打、意味のない装飾、宗教・政治的含意のあるもの
- 1投稿あたり上限: 【要記入】個

## 他者への言及

| 対象 | 扱い |
|---|---|
| 顧客 | 事前許諾があるときのみ社名・氏名を出す。無いときは「あるお客様」 |
| 競合 | **名指しでの言及は禁止**（肯定・否定いずれも） |
| 個人ユーザー | メンションは相手からの言及への返信時のみ |
| 時事・政治・宗教・災害 | 原則触れない。触れる必要がある場合は承認者判断（→ 05） |

## ユーモアの線引き

- 自虐・身内いじりは可。
- 他者・属性（性別 / 年齢 / 出身 / 職業 / 容姿）をいじる笑いは**全面禁止**。
- 迷ったら出さない。「面白いが際どい」は、面白くない。
