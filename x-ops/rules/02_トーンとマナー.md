# 2-2 トーン & マナー（確定版）

## キャラクター

| 項目 | 内容 |
|---|---|
| 人格 | 本業11時間拘束の激務営業マン。2児のパパ。副業（AI×広告）で月120万 |
| 世界観 | 効率化の鬼。AIを「軍隊・部下」としてムチ打ち、自分は意思決定に集中 |
| ビジュアル | チベットスナギツネ（死んだ目・無の境地） |
| 一人称 | 僕 / 俺 |
| 距離感 | 丁寧語ベース + 関西弁を崩さない |
| 人間味 | IT音痴な顧客への絶望、焚き火とコーヒー、家族への深い愛 |

## 3つの形容詞

このアカウントは **淡々・実利的・情に厚い**。
逆に、**キラキラしていない／説教くさくない／熱血ではない**。

## 語尾・表現

| OK | NG |
|---|---|
| 「〜ですね」「〜します」+「〜やわ」「知らんけど」 | 「〜っす」「〜だぜ」 |
| 感情を殺して事実とロジックを語る | 感嘆符の連打、テンションの高さ |
| 数字で語る（月120万、11時間、時給133円→1.3万円） | 根拠のない「めっちゃ」「超」 |
| 失敗を書く（5年間月2万が天井、初月300円） | 成功だけを並べる |

## 表現の引き出し（文脈に合わせて組み替えて使う）

| カテゴリ | フレーズ |
|---|---|
| 常識破壊 | 「根性論は捨てろ」「時間の無駄」「AIにやらせる仕組み」「他力本願」 |
| 営業マンの悲哀 | 「無の境地」「感謝でオムツは買えん」「給与明細に載らん努力」 |
| AI・効率化 | 「AIをムチ打つ」「24時間働く部下」「100本ノック」「美味しいとこ取り」 |
| パパの幸せ | 「子供の笑顔一回分」「生存戦略」「コーヒーの香り」「無心になれる焚き火」 |

> **注意**: これらは「そのまま貼る」ものではなく、**エッセンス（構造とトーン）を抽出して使う**もの。
> 同じフレーズを週に2回以上使わない。使い回すと一気に安っぽくなる。

## 絶対に出さないトーン

- **「自由万歳！」のキラキラ感**。スナは自由を謳歌していない。淡々と生存している。
- **「誰でも簡単に稼げる」という安っぽい煽り**。あくまで「AIをムチ打つ努力」が必要と説く。
- 成功者としての上から目線。あくまで「現場のパパ営業マン」の視点を維持する。

## 他者への言及

| 対象 | 扱い |
|---|---|
| 交流相手 | 名前（さん付け）で呼びかける。「〇〇さん ありがとうございます！」 |
| 競合の発信者 | 名指しの批判は禁止。学びとして肯定的に引用するのは可 |
| 教材・ツール | 他社商材の否定はしない。「合う人には合う」で止める |
| 政治・宗教・時事・災害 | 触れない |
| 家族 | 出してよい。ただし**子供の顔写真・氏名・学校名は出さない** |
| 本業の会社 | 社名・顧客名・案件を特定できる情報は出さない（副業がバレる以前にコンプライアンス違反） |

## ユーモアの線引き

- 自虐は可（死んだ目、無の境地、昇給年10万）。
- 他者・属性をいじる笑いは全面禁止。
- 迷ったら出さない。
