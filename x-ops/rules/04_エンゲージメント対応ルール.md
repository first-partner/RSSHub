# 2-4 リプライ・DM・引用ポスト対応ルール

## 対応方針マトリクス

| 種類 | 対応 | 目安時間 | 担当 |
|---|---|---|---|
| 好意的なリプライ | いいね（+ 余力があれば返信） | 当日中 | 運用担当 |
| 質問（一般的） | 返信。答えられない場合は問い合わせ窓口へ誘導 | 【4】営業時間以内 | 運用担当 |
| 質問（個別契約・仕様） | 公開返信せずDM or 窓口誘導 | 【4】営業時間以内 | 運用担当 |
| 不具合・クレーム報告 | **公開の場で事実確認を約束 → 窓口へ**。言い訳・反論はしない | 【2】営業時間以内 | 運用担当 → 承認者へ即共有 |
| 誹謗中傷・荒らし | 返信しない。ブロック/ミュートは承認者判断 | — | 承認者 |
| 明らかなスパム | 通報・ブロック | — | 運用担当 |
| 好意的な引用ポスト | いいね（リポストは内容確認の上） | 当日中 | 運用担当 |
| 批判的な引用ポスト | 反応しない。拡散状況のみ監視 | — | 承認者へ共有 |

## 返信の原則

1. **反論しない。** 公開の場での議論は勝っても損。
2. **謝罪と事実確認を分ける。** 「ご不便をおかけしました」（謝る）と「事実を確認します」（約束）は別。
3. **DMに逃がすときは理由を書く。** 「個別のご契約内容にあたるため」など。
4. **返信しないことも選択肢。** 沈黙は不誠実ではなく、判断。

## 返信テンプレート

- **感謝**: 「ありがとうございます。そう言っていただけて励みになります。」
- **質問対応**: 「ご質問ありがとうございます。◯◯については△△です。詳細はこちらをご覧ください → URL」
- **不具合報告**: 「ご報告ありがとうございます。ご不便をおかけし申し訳ありません。事実確認のうえ、こちらのフォームよりご連絡いただけますと個別に対応いたします → URL」
- **答えられない**: 「お問い合わせいただきありがとうございます。個別のご状況に関わる内容のため、恐れ入りますがサポート窓口までご連絡ください → URL」

## こちらから行うアクション

| 行為 | 可否 | 条件 |
|---|---|---|
| いいね | 可 | 自社言及・業界情報。政治/宗教/センシティブな投稿には絶対に押さない |
| フォロー | 【要記入】 | 誰をフォローするかの基準を決める（顧客・パートナー・業界メディア等） |
| リポスト | 可 | 自社・パートナー・許諾済みの顧客言及のみ |
| フォロー返し | 【要記入】 | |
| DMからの営業 | 禁止 | |

> **注意**: 公式アカウントの「いいね」は第三者から見える。いいね＝賛意と受け取られる前提で押すこと。
