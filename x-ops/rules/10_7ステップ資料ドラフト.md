# オファー資料「毎日2時間で月120万にした AI×広告の7ステップ」ドラフト

> **【★】の欄だけご自身で埋めてください。それ以外は書いてあります。**
> 3〜4時間と見積もっていた作業が、1時間程度で終わるはずです。

---

## 0. 作る前に：PDFにしないという選択

**プロラインフリーの「コンテンツページ」機能で作ることを推奨します。** 理由は3つ。

| | PDF | プロラインのコンテンツページ |
|---|---|---|
| 制作の手間 | レイアウト調整が要る | テキストを流し込むだけ |
| スマホでの読みやすさ | 拡大縮小が必要で読みにくい | そのまま読める |
| 修正 | 作り直して再アップ | その場で直せる |

ペルソナは**通勤電車のスマホで読みます。** PDFは開いた瞬間に閉じられます。
URLもプロラインが発行してくれるので、1通目にそのまま貼れます。
フリープランでもコンテンツページは無制限に作れます。

## 1. 冒頭（そのままコピペ）

```
毎日2時間で月120万にした
AI×広告の7ステップ

──────────────

開く前に、一個だけ言うときます。

この中に、具体的な手順は書いてません。
クライアントとの契約があるんで、書けん部分があります。

出し惜しみやなくて、ほんまに書けん。

書いたのは全体の流れです。
どこを通るかは分かるけど、歩き方までは書いてない。

それでも渡す意味はあると思ってます。
僕は5年間これを持たずに歩いて、月2万で止まってました。
どこで詰まってるのかすら分かってなかったので。

あと、各ステップの最後に
「僕がここでやらかしたこと」を書いてます。

正直、書きたない話ばっかりです。
ただ、うまくいった話より、そっちのほうが役に立つと思うので。
```

## 2. 7ステップ本文

### ■ STEP 1｜土俵を決める

```
【やること】
どのジャンルの商品を扱うか、1つに絞る。

世の中の商品を全部やるわけにいかんので、まず土俵を決めます。

【なぜここが要るのか】
ここが決まらんと、この先が全部決まりません。
選ぶ商品も、書く文章も、出す広告も、全部ここに引っ張られます。

逆に、ここさえ決まったら、あとはだいぶ機械的です。

【かかる時間】
【★ 要記入：あなたの場合どのくらいかかったか】

【僕がここでやらかしたこと】
【★ 要記入】
例）「好きなジャンル」で選んで1年溶かしました。
　　市場は、僕が何を好きかなんか一切見てくれんかったです。
```

### ■ STEP 2｜商品を選ぶ

```
【やること】
決めた土俵の中から、実際に紹介する商品を1つ選ぶ。

ASPというところに登録すると、
紹介できる商品が一覧で見られるようになります。その中から選びます。

見るとこは3つです。

　① もう誰かが売れてるか
　② 報酬が広告費に見合うか
　③ そもそも広告を出してええ商品か

③を外すと、どれだけ売れても報酬がゼロになります。
最悪、アカウントごと止まります。

【なぜここが要るのか】
ここで8割決まります。
文章がうまかろうが、売れん商品は売れません。

【かかる時間】
【★ 要記入】

【僕がここでやらかしたこと】
【★ 要記入】
例）報酬額だけ見て選んで、全部外しました。
　　単価が高いのは、高い理由があるだけでした。
```

### ■ STEP 3｜受け皿を作る

```
【やること】
広告をクリックした人が最初に着くページを用意する。自分のサイトです。

【なぜここが要るのか】
広告から公式サイトに直接飛ばすのは、ルール上できません。
なので間に自分のページが要ります。

ここは凝らんでええです。
役割は「クリックした人を迷わせずに次に送る」だけなんで。

【かかる時間】
【★ 要記入】

【僕がここでやらかしたこと】
【★ 要記入】
例）作り込みすぎて、公開まで3ヶ月かかりました。
　　その3ヶ月、売上は当然ゼロです。
　　7割の出来で出して、あとで直したらよかった。
```

### ■ STEP 4｜広告を出す

```
【やること】
Google広告のアカウントを作って、検索結果に自分のページを出す。
お金を払って、検索結果の枠を買います。

【なぜここが要るのか】
ここがこのビジネスの心臓です。

ブログやSNSと決定的に違うのはスピードで、
出した日から人が来ます。1日で結果が分かる。

僕が5年ダメで、切り替えてから4ヶ月で変わったのは、
才能とかやなくて、単純にここの速さの差です。

【かかる時間】
【★ 要記入】

【僕がここでやらかしたこと】
【★ 要記入】
例）初日に予算を溶かしました。
　　「とりあえず出してみるか」で、一晩で【★金額】円。
　　朝起きて管理画面見たときの気持ちは、今でも覚えてます。
```

### ■ STEP 5｜数字を見る

```
【やること】
出した広告の数字を見る。見る数字は決まってます。

　・どれだけ表示されたか
　・どれだけクリックされたか
　・クリック1回にいくら払ったか
　・何件売れたか
　・差し引きいくら残ったか

【なぜここが要るのか】
このビジネス、全部が数字で見えます。
勘でやらんでええ。営業とはここが一番違うとこです。

数字を見んかったら、まず勝てません。
運で勝てても続かんので。

【かかる時間】
【★ 要記入】（1日あたり何分見てるか）

【僕がここでやらかしたこと】
【★ 要記入】
例）見る数字を間違えてて、判断が全部逆でした。
　　クリックが多い＝ええこと、やと思ってたんです。
　　実際に見なあかんのは、そこやなかった。
```

### ■ STEP 6｜止める、伸ばす

```
【やること】
数字を見て、赤字のものを止める。黒字のものに寄せる。

【なぜここが要るのか】
最初から当たることは、まずないです。
10個出して1個当たれば上等。

で、当たりを見つけるより、外れを切るほうがしんどいです。
「もうちょっとで当たるかも」が、いつまでも消えんので。

【かかる時間】
【★ 要記入】

【僕がここでやらかしたこと】
【★ 要記入】
例）止められませんでした。
　　撤退ラインを先に決めてへんかったせいで、損失だけ伸びました。
```

### ■ STEP 7｜AIに任せる

```
【やること】
ここまでの工程のうち、「考える」以外を全部AIに渡す。

　・書く
　・案を出す
　・整える

自分がやるのは決めることだけです。

【なぜここが要るのか】
僕は本業が1日11時間拘束で、副業に使えるのは2時間です。
全部自分でやってたら、どう考えても回りません。

AIは24時間働く部下です。文句も言わんし辞めもしません。
ムチ打つ相手がおるって、なかなかええですよ。

【かかる時間】
【★ 要記入】

【僕がここでやらかしたこと】
【★ 要記入】
例）全部任せようとして、全部やり直しになりました。
　　AIは「決める」ができひん。そこは人間の仕事でした。
```

## 4. 書くときの注意

| | |
|---|---|
| ❌ 書かない | 具体的な設定手順 / 除外KWリスト / 案件名 / ASP名の攻略法 / テンプレート / ツール名の詳細 |
| ✅ 書く | 何をやるか / なぜ要るか / 時間 / **どこでやらかしたか** |

> **【★】の「やらかしたこと」が、この資料の価値の8割です。**
> 手順は出せなくても、失敗は出せます。そして失敗のほうが刺さります。
> 例文はあくまで叩き台なので、**実際にあったことに置き換えてください。**
> 金額や期間が具体的なほど効きます（「一晩で3万溶かした」など）。

分量はこれで A4換算 7〜9ページ相当です。**これ以上足さないでください。**
