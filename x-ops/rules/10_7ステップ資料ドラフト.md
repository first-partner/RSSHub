### ここから言えること

1. **総額はほぼ合っています（差4.9%）。** つまり、まったく別の数字ではなく、**同じ実績を見ています。**
2. **初月と4ヶ月目は、丸めで説明がつきます。**
3. **食い違っているのは2ヶ月目と3ヶ月目だけ。** しかも**その2ヶ月の合計は6.5%差しかない**ので、
   **総額は同じで、2月と3月への配分だけが入れ替わっている**形です。
4. **𝕏の並び（2万→60万→80万→120万）は、きれいな単調増加になっています。**
   実際は2ヶ月目がピークで、3ヶ月目に下がっています。

### 「承認率の違い」では説明がつきません

「𝕏＝確定報酬 / 資料＝売上」なら差は説明できるはずですが、計算が合いません。

| 月 | 𝕏 ÷ 資料 | |
|---|---|---|
| 初月 | **147%** | ← 売上を超えている。あり得ない |
| 2ヶ月目 | 68% | |
| 3ヶ月目 | **131%** | ← 売上を超えている。あり得ない |
| 4ヶ月目 | 96% | |

**確定報酬が売上を超えることはないので、この説は破綻します。**

### 残る可能性は2つ。**どちらかを選んでください**

| | 説明 | 対応 |
|---|---|---|
| **A** | 𝕏投稿時に、記憶・概算で書いた（または、きれいな右肩上がりに整えた） | **資料が正。𝕏を訂正する（下に案）** |
| **B** | 𝕏は着金・確定ベース、資料は発生ベース。計上月のズレで2月と3月が入れ替わった | **どちらも正しい。資料に定義の1行を入れて終わり** |

> **総額がほぼ一致していることから、Bの可能性も十分あります。**
> ASPの確定は発生から1〜2ヶ月遅れるので、月をまたぐと順序が入れ替わることは実際に起きます。
> **通帳・ASPの管理画面を見れば、どちらか分かります。**

Aだった場合（あるいはBでも、並びが誤解を招く以上）、**訂正を1回出すことを強く推奨します。**

理由は3つ。

1. 過去投稿はリポストで残っており、資料を読んだ人が遡ると気づきます

3. **3ヶ月目の減収を𝕏で先に出しておけば、資料を読んだときに一貫します**

```
でも無理です。
本業は11時間拘束のままやし、
子供が起きてる時間を削るのは、
そもそも何のためにやってるか分からんくなる。

なので、時間を増やすんやなくて、
1回あたりの時間を減らすことにしました。

──────────────

やったのは2つです。

ひとつは、AIに渡すこと。

　・文章を書く
　・案を出す
　・整える

この3つは全部AIに投げて、自分は「決める」だけにしました。
AIは24時間働くし、文句も言わんし、辞めません。

ただ、AIに渡しても減らん作業がありました。

　案件を探す
　広告を出す
　広告を更新する

ここは手を動かすしかない。
数が多いだけで、頭は使わん作業です。

なので、道具を作りました。

　・各種ASPから案件をピックアップするツール
　・Google広告を一括で出稿・更新するツール

30分かかってた案件探しが、5分になりました。
40分かかってた出稿が、5分になりました。

正確に言うと、ツールが動いてる間は別のことをしてるので、
実際に僕が使ってるのは、設定と調整の時間だけです。

──────────────

結果、作業時間が2時間に戻りました。

大事なのは、
1時間が2時間に増えたことやなくて、
2時間の中身が変わったことです。

昔の1時間は、ほとんど手を動かす時間でした。
今の2時間は、ほとんど決める時間です。

──────────────

4ヶ月目の結果は、1,244,981円でした。

嫁に通帳を見せたときの顔は、たぶん一生忘れません。

「え、嘘やん。ほんまに？」しか言わんかったですけど。
```
