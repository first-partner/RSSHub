# オファー資料「毎日2時間で月120万にした AI×広告の7ステップ」ドラフト

> **【★】の欄だけご自身で埋めてください。それ以外は書いてあります。**
> 3〜4時間と見積もっていた作業が、1時間程度で終わるはずです。

## 0. 作る前に：PDFにしないという選択

**プロラインフリーの「コンテンツページ」機能で作ることを推奨します。** 理由は3つ。

| | PDF | プロラインのコンテンツページ |
|---|---|---|
| 制作の手間 | レイアウト調整が要る | テキストを流し込むだけ |
| スマホでの読みやすさ | 拡大縮小が必要で読みにくい | そのまま読める |
| 修正 | 作り直して再アップ | その場で直せる |

ペルソナは**通勤電車のスマホで読みます。** PDFは開いた瞬間に閉じられます。
URLもプロラインが発行してくれるので、1通目にそのまま貼れます。
フリープランでもコンテンツページは無制限に作れます。

## 1. 構成を「手順書」から「物語」に変えました

前の版は7つのステップを並べた手順書でした。読んでも心が動きません。
**「なるほど」で終わって、「やってみよう」にならない。**

なので、**半年の時系列を主軸にして、7つのステップをその中に埋め込みました。**

| | 前の版 | この版 |
|---|---|---|
| 軸 | ステップ1〜7の並列 | **月ごとの時系列** |
| 7ステップの扱い | 見出しとして並ぶ | **その月に立ちはだかった壁として登場する** |
| 感情 | なし | 焦り → 恐怖 → 手応え → 限界 → 仕組み化 |
| ツールの登場 | 別枠の特典案内 | **物語の必然として出てくる** |
| 読後 | 「そういう流れか」 | **「これなら自分もいけるかもしれん」** |

### 仕込んである4つの狙い

| # | 読者に持ってほしい感情 | 仕掛け |
|---|---|---|
| 1 | 自分でも出来るかもしれない | **各章の冒頭に「そのときの1日のスケジュール」を置く。** 読者と同じ生活が並ぶ |
| 2 | 忙しいスナでも出来た | 本業11時間拘束が**最後まで変わらない**。環境は変わっていない、と示す |
| 3 | 1日1時間でもスモールステップでいける | 1ヶ月目の副業時間は**1時間だけ**。そこから積み上がる形にした |
| 4 | 他の人より、スナから買うほうがいい | **ツールが第4章で「時間が足りなくて自分で作った」流れで出てくる。** 特典の押し売りにならない |

> **【★】がご自身にしか書けない箇所です。** それ以外は書いてあります。
> 例文は叩き台なので、**実際にあった具体に置き換えてください。**
> 特に金額・時刻・場所・人の言葉は、具体的なほど効きます。

## 4. 書くときの注意

### 出す / 出さない

| | |
|---|---|
| ❌ 出さない | 具体的な設定手順 / 除外KWリスト / 案件名・ジャンル名 / ASP攻略 / テンプレート / ツールの中身 |
| ✅ 出す | **何をやったか / そのとき何を考えてたか / どこで詰まったか / 数字 / 情景** |

### 【★】を埋めるときのコツ

**具体的なほど効きます。** 抽象的な苦労は、誰の心も動かしません。

| 弱い | 強い |
|---|---|
| 苦労しました | 2時に寝て6時に起きる日が続いて、商談で相手の名前を間違えました |
| お金を溶かしました | 朝起きて管理画面を見て、トイレでしばらく出られんかったです |
| 家族が喜んでくれました | 「え、ほんまに？」しか言わんかったです |
| 時間が足りませんでした | 案件探しに30分、出稿に40分、数字を見るのに30分。1時間では終わらん |

### ⚠️ エピローグの「子供の絵」について

プロローグ（寝てる姿の絵）とエピローグ（起きてる僕の絵）で対になる構成にしていますが、
**エピローグ側が事実でないなら、絶対に書かないでください。**

作り話は、いずれどこかで矛盾します。
そして**この資料の力は、全部「本当のことしか書いてない」ことから来ています。**
一箇所でも作ると、他の全部が疑われます。

事実でないなら、実際に起きた別の変化に置き換えてください。
「変わったこと」は、半年もあれば他にいくらでもあるはずです。

### 分量

A4換算で12〜15ページ相当。前の版（7〜9ページ）より長くなっています。

**長さは問題ありません。** 手順書は長いと読まれませんが、**物語は長くても読まれます。**
むしろ、途中でやめられないほうが大事です。

ただしスマホで読むので、
- 章のあいだに区切り線（──────────────）を必ず入れる
- 1つの段落は3行まで
- 【この頃の1日】のような**視覚的に休める箱**を各章に置く
