# オファー資料「毎日2時間で月120万にした AI×広告の7ステップ」ドラフト

> **【★】の欄だけご自身で埋めてください。それ以外は書いてあります。**
> 3〜4時間と見積もっていた作業が、1時間程度で終わるはずです。

---

## 0. 作る前に：PDFにしないという選択

**プロラインフリーの「コンテンツページ」機能で作ることを推奨します。** 理由は3つ。

| | PDF | プロラインのコンテンツページ |
|---|---|---|
| 制作の手間 | レイアウト調整が要る | テキストを流し込むだけ |
| スマホでの読みやすさ | 拡大縮小が必要で読みにくい | そのまま読める |
| 修正 | 作り直して再アップ | その場で直せる |

ペルソナは**通勤電車のスマホで読みます。** PDFは開いた瞬間に閉じられます。
URLもプロラインが発行してくれるので、1通目にそのまま貼れます。
フリープランでもコンテンツページは無制限に作れます。

```

先に言っておきます。
```

## 2. 7ステップ本文

### ■ STEP 1｜土俵を決める

```
【やること】
どのジャンルの商品を扱うか、1つに絞る。

世の中の商品を全部やるわけにはいきません。
まず土俵を1つに決めます。

【なぜここが要るのか】
土俵が決まらないと、この後の全部が決まりません。
選ぶ商品も、書く文章も、出す広告も、全部ここに引っ張られます。

逆に言うと、ここさえ決まれば、あとは流れ作業に近い。

【かかる時間】
【★ 要記入：あなたの場合どのくらいかかったか】

【僕がここでやらかしたこと】
【★ 要記入】
例）「好きなジャンル」で選んで1年溶かしました。
　　市場は、僕が何を好きかなんて一切関係なかった。
```

### ■ STEP 2｜商品を選ぶ

```
【やること】
決めた土俵の中から、実際に紹介する商品を1つ選ぶ。

ASPという仲介サービスに登録すると、
紹介できる商品が一覧で見られるようになります。

その中から選びます。

見るべき観点は3つです。

　① すでに誰かが売れているか
　② 報酬が広告費に見合うか
　③ 広告を出していい商品か  ← ここを外すと全部が無駄になります

【なぜここが要るのか】
商品選びで勝負の8割が決まります。
文章がうまくても、売れない商品は売れません。

特に③。
広告を出してはいけない商品を選ぶと、
どれだけ売れても報酬がゼロになります。最悪、アカウントが止まります。

【かかる時間】
【★ 要記入】

【僕がここでやらかしたこと】
【★ 要記入】
例）報酬額だけ見て選んで、全部外しました。
　　単価が高い商品は、高い理由があるだけでした。
```

### ■ STEP 3｜受け皿を作る

```
【やること】
広告をクリックした人が最初に着くページを用意する。
自分のサイトです。

【なぜここが要るのか】
広告から公式サイトに直接飛ばすことは、ルール上できません。
だから、間に自分のページが要ります。

ここは凝らなくていい。
役割は「クリックした人を、迷わせずに次へ送る」だけです。

【かかる時間】
【★ 要記入】

【僕がここでやらかしたこと】
【★ 要記入】
例）作り込みすぎて、公開まで3ヶ月かかりました。
　　その3ヶ月、売上はゼロです。
　　7割の出来で出して、あとで直せばよかった。
```

### ■ STEP 4｜広告を出す

```
【やること】
Google広告のアカウントを作って、検索結果に自分のページを表示させる。

お金を払って、検索結果の枠を買う。それだけです。

【なぜここが要るのか】
ここがこのビジネスの心臓です。

ブログやSNSと決定的に違うのは、スピード。
出した日から人が来ます。だから1日で結果が分かる。

僕が5年間ダメで、切り替えてから4ヶ月で変わったのは、
ここのスピードの差です。

【かかる時間】
【★ 要記入】

【僕がここでやらかしたこと】
【★ 要記入】
例）初日に予算を溶かしました。
　　「とりあえず出してみよう」で、一晩で【★金額】円。
```

### ■ STEP 5｜数字を見る

```
【やること】
出した広告の数字を見る。見る数字は決まっています。

　・どれだけ表示されたか
　・どれだけクリックされたか
　・クリック1回にいくら払ったか
　・何件売れたか
　・差し引き、いくら残ったか

【なぜここが要るのか】
このビジネスは、全部が数字で見えます。
感覚でやらなくていい。ここが営業と決定的に違うところです。

逆に言うと、数字を見ない人は絶対に勝てません。
運で勝つことはあっても、続きません。

【かかる時間】
【★ 要記入】（1日あたり何分見ているか）

【僕がここでやらかしたこと】
【★ 要記入】
例）見る数字を間違えていて、判断が全部逆でした。
　　クリック数が多い＝good だと思ってた。
　　実際に見るべきは、そこじゃなかった。
```

### ■ STEP 6｜止める、伸ばす

```
【やること】
数字を見て、赤字のものを止める。黒字のものにお金を寄せる。

それだけです。

【なぜここが要るのか】
最初から当たることは、まずありません。
10個出して1個当たれば上等です。

大事なのは、外れを早く切ること。
当たりを見つけることじゃなくて、外れを切ることのほうが難しい。

【かかる時間】
【★ 要記入】

【僕がここでやらかしたこと】
【★ 要記入】
例）止められませんでした。
　　「もう少しで当たるかも」で、損失だけ伸ばしました。
　　撤退ラインを先に決めていなかったのが原因です。
```

### ■ STEP 7｜AIに任せる

```
【やること】
ここまでの工程のうち、「考える」以外を全部AIに渡す。

　・文章を書く
　・案を出す
　・整える

自分がやるのは、決めることだけです。

【なぜここが要るのか】
僕は本業が1日11時間拘束です。副業に使えるのは2時間。
全部自分でやってたら、絶対に回りません。

AIは24時間働く部下です。文句も言わんし、辞めません。
ムチ打つ相手がおるって、ええもんですよ。

【かかる時間】
【★ 要記入】

【僕がここでやらかしたこと】
【★ 要記入】
例）全部任せようとして、全部やり直しになりました。
　　AIは「決める」ができない。そこは人間の仕事でした。
```

## 4. 書くときの注意

| | |
|---|---|
| ❌ 書かない | 具体的な設定手順 / 除外KWリスト / 案件名 / ASP名の攻略法 / テンプレート / ツール名の詳細 |
| ✅ 書く | 何をやるか / なぜ要るか / 時間 / **どこでやらかしたか** |

> **【★】の「やらかしたこと」が、この資料の価値の8割です。**
> 手順は出せなくても、失敗は出せます。そして失敗のほうが刺さります。
> 例文はあくまで叩き台なので、**実際にあったことに置き換えてください。**
> 金額や期間が具体的なほど効きます（「一晩で3万溶かした」など）。

分量はこれで A4換算 7〜9ページ相当です。**これ以上足さないでください。**
