# 2-3 NG・禁止事項

> ここに触れるものは、面白くても、伸びても、出さない。判断に迷ったら投稿しないのが正解。

## A. 絶対禁止（例外なし）

- 差別・侮辱（人種 / 国籍 / 性別 / 性的指向 / 宗教 / 障害 / 職業 / 容姿）
- 政治的主張、特定政党・候補者への支持または批判
- 宗教的主張
- 他社・他者への誹謗中傷、名指しの比較批判
- 未公開情報（人事・業績・提携・製品）の言及
- 顧客情報・個人情報を特定できる内容（画面キャプチャの中の氏名・メールアドレス含む）
- 社内の写真・画面のうち、機密が写り込むもの
- 第三者の著作物（画像・文章・音楽・動画）の無断使用
- 他ユーザーの投稿のスクリーンショット無断転載
- 事実確認していない数字・引用
- ステルスマーケティング（PR案件は必ず `#PR` を明示）
- 現金・金券を直接配布するプレゼント企画（規約・法令の確認が済むまで）

## B. 要承認（承認者の確認なしに出さない）

- 時事ニュース・社会的話題への言及
- 災害・事故・訃報に関する投稿
- 自社の不具合・障害・お詫び
- 価格・キャンペーン・数量限定に関する表記
- 効果効能に触れる表現
- 他社アカウントとの絡み（引用・コラボ）
- 中の人の私的な話題

## C. 法令チェック観点

| 法令 | 気をつける表現 | 代替 |
|---|---|---|
| 景品表示法（優良誤認） | 「No.1」「最高」「日本一」 | 出典と調査条件を併記。無ければ削除 |
| 景品表示法（有利誤認） | 「今だけ」「業界最安」 | 期間・条件を明記 |
| 薬機法 ※該当業種のみ | 「治る」「効く」「改善する」 | 「〜と言われています」ではなく、そもそも書かない |
| 著作権法 | 引用の要件（主従関係・出典・改変なし） | 引用元URLを必ず併記 |
| 肖像権・パブリシティ権 | 人物写真 | 書面許諾を取得 |
| 医療・金融・不動産等の業法 | 【要記入：該当有無】 | |

> 該当業種かどうかは `HEARING.md` で確認します。該当する場合、このページに業法別の詳細チェックリストを追加してください。
