# 2-3 NG・禁止事項（情報発信・教材販売版）

> このアカウントは「PPCアフィリエイト教材を売る個人発信」。
> 企業公式より**法規制のリスクは高い**。伸びても、ここに触れるものは出さない。

## A. 絶対禁止（例外なし）

- **「必ず稼げる」「絶対」「誰でも簡単に」** など、成果を保証する表現
- 再現性の裏付けがない収益額の提示（自分の実績以外の数字を、あたかも標準のように語る）
- 受講生・購入者の実績を**許諾なく**掲載する
- 本業の会社名・顧客名・案件が特定できる情報
- 子供の顔・氏名・通う園や学校が特定できる情報
- 差別・侮辱（人種／国籍／性別／年齢／職業／容姿）
- 政治的・宗教的主張
- 他の発信者・他社教材への名指し批判
- 第三者の投稿のスクリーンショット無断転載、画像・文章の無断使用
- ステルスマーケティング（PR案件・アフィリエイトを含む投稿は必ず明示）
- 現金・金券を直接配布するプレゼント企画
- ASPやGoogle広告の**規約違反を推奨する内容**（商標KWの無断出稿を勧める等）

## B. 要セルフレビュー（投稿前に一度手を止めて読み返す）

- 具体的な金額・期間を出す投稿（「◯ヶ月で◯万」）
- 教材・Zoom・LINEへの導線が入る投稿
- 時事・社会的話題への言及
- 中の人の私的な話題（家族の描写）
- 他アカウントとの絡み（引用・コラボ）

## C. 法令チェック観点

| 法令 | 危ない表現 | 対応 |
|---|---|---|
| **景品表示法（優良誤認）** | 「絶対稼げる」「誰でも」「No.1」 | 使わない。「僕の場合は」「合う人には」に置き換える |
| **景品表示法（有利誤認）** | 「今だけ」「特別価格」「残り◯名」 | 期間・条件・根拠を必ず明記。虚偽の限定は不可 |
| **ステマ規制（景表法・2023年〜）** | 広告なのに広告と分からない投稿 | 対価が発生する紹介は `#PR` または「広告」と明示 |
| **特定商取引法** | 教材販売ページの表記 | 特商法表記ページを常に有効に保つ。𝕏側は導線のみ |
| **著作権法** | 他人の投稿・記事のコピー | 引用は「主従関係・出典明記・改変なし」を守る。𝕏記事の引用リポストは引用元がリンクで残るのでOK |
| **𝕏の利用規約** | 下記「D」を参照 | |

## D. 𝕏のプラットフォームポリシー（**交流施策の最大リスク**）

1日20〜30本の引用リポストは、**やり方を間違えるとスパム判定を受けます**。
𝕏の「プラットフォーム操作とスパム」ポリシーで問題になるのは、主に次の3つです。

| リスク | 具体 | 回避ルール |
|---|---|---|
| **定型文の反復** | 同じ文面・ほぼ同じ文面を複数アカウントに投げる | **相手の投稿内容に具体的に触れた一文を必ず入れる**。テンプレの丸コピは禁止 |
| **無差別な大量アクション** | 短時間に集中して大量に引用・リプ | 1回の作業を**20分以上あけて2〜3セットに分割**。一気に30本連投しない |
| **相互エンゲージメントの組織化** | 「いいね返し」「フォロバ100%」への過度な参加 | 相互目的だけの引用はしない。**内容に価値を足せない相手には絡まない** |

> 凍結・シャドウバンが起きると、それまでの積み上げが全部止まります。
> **量を追うほど、1本ごとの「自分の言葉」が凍結を防ぐ保険になります。**
