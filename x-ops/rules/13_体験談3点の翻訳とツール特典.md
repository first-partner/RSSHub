# LPの3点をスナの体験談に翻訳する／ツール特典の設計

---

## 1. まず、そのままだと衝突します

LPの3点を**そのままスナの言葉で語ると、これまで積んだキャラが壊れます。**
理由は2つ。

### 衝突① 「簡単な作業でできる手法」

これは `03_NG禁止事項` と `02_トーンとマナー` に明記した**NGそのもの**です。

> ■NG事項
> 「誰でも簡単に稼げる」といった安っぽい煽りはNG
> （あくまで「AIをムチ打つ努力」が必要と説く）
> ── 出典: Google Drive『X運用-配信戦略の意図・コンテンツ設計・ルール』

スナのペルソナは **「キラキラした副業インフルエンサーを見ると、自分とは住む世界が違うと余計に冷める」** 人です。
「簡単」は、この層が最も警戒する言葉です。

### 衝突② 「1日1時間」

アカウント名が **「毎日2時間で月120万の営業パパ」** です。
プロフィールに2時間と書いてある人が1時間と語ると、読者は数字のズレに気づきます。
**数字が合わない人は、それだけで信用されません。**

## 2. 翻訳表（嘘をつかずに、むしろ強くする）

3点とも、**事実を曲げずに翻訳できます。しかも翻訳したほうが刺さります。**

| LPのコピー | スナの言葉 | なぜこちらが効くか |
|---|---|---|
| **1日1時間のスキマ時間で** | 「始めた頃は1日1時間しか取れんかった。今は2時間やけど、実作業が1時間切る日もあります」 | 時系列で語れば矛盾しない。**過去形で語ると「今の自分と同じ状態だった人」に見える** |
| **簡単な作業でできる手法** | **「作業自体は難しないです。難しいのは、やることを決めるまで」** | 「簡単」と言われると疑うが、「決めるのが難しい」と言われると納得する。しかも **Zoomの存在理由と完全に一致する** |
| **1万から積み上げ6〜7桁** | 「初月2万。2ヶ月目60万。3ヶ月目80万。4ヶ月目120万」 | 実データがそのまま該当。**盛る必要がない**。ただし「あなたも」は言わない（景表法） |

### 2点目の翻訳が、実は導線全体を強くします

```
「作業自体は難しない。難しいのは、やることを決めるまで」
        ↓
7ステップ資料は「What」だけで「How」を出さない
        ↓
「で、自分の場合どう決めたらええん？」が残る
        ↓
それを相談する場が Zoom
```

**「簡単」と言うと、Zoomが要らない理屈になります。**
「決めるのが難しい」と言えば、Zoomが要る理屈になります。
翻訳は、キャラを守るためだけでなく、**導線を通すために必要**です。

## 3. ツール特典 ── これが差別化の核です

> ・各種ASPの案件抽出ツール
> ・Google広告 一括出稿・更新ツール

**これは特典ではなく、体験談の裏付けです。** 位置づけを一段上げてください。

### なぜ強いか

| # | 理由 |
|---|---|
| 1 | **「なんで1日1時間で回るんか」への答えそのもの。** 3点の1つ目を、根拠つきで語れるようになる |
| 2 | ペルソナの最大の痛み（時間がない）に直撃する。ツール＝時間 |
| 3 | 同じ教材は他の人からも買えます。**スナから買う理由**がこれで立つ |
| 4 | **Zoom実施者が別の人である問題を、部分的に解決する** ← 後述 |

### 語りの流れ（この順序で一本になります）

```
「1日1時間で回してます」
      ↓ なんで？
「作業自体は難しないからです。ただ、そのままやと1時間では終わらん」
      ↓ じゃあ？
「案件を探すのと、広告を出すのに時間が食われるんで、自分でツール作りました」
      ↓
「僕経由で契約してもろた人には、そのツールをそのまま渡してます」
```

**盛らずに、特典が「当然の帰結」として出てきます。**

### ★ 信頼の断絶への効き目

これまで「Zoomに出るのがスナ本人でないこと」を最大のリスクとして扱ってきました。
**ツール特典は、その解決策として同席より効く可能性があります。**

> Zoomで別の人が話しても、**「スナ経由で契約すればツールがもらえる」という理由が残る限り、
> スナとの関係は切れません。**
>
> 参加者の頭の中は「知らん人が60万の説明をしている」ではなく、
> 「スナさんのツールをもらうために、この人の話を聞いている」になります。

**この一点だけで、成約率が変わる可能性があります。**

### 出すタイミング ── 5通目までは絶対に出さない

| | |
|---|---|
| ❌ 早く出す | 「特典目当て」の人が集まる。ツールは**買う理由**であって**登録する理由**ではない |
| ❌ Zoom後に出す | Zoom実施者はスナの特典を説明できません。**手遅れになります** |
| ✅ **Zoomの直前（6通目）** | 申込の動機が上がり、かつ当日「スナのツール」が頭に残った状態でZoomに入る |

### 特典の表記（トラブル防止）

曖昧にすると必ず揉めます。次の4点を明記してください。

- [ ] **対象**: 誰経由の契約が対象か（「このLINEから申し込んで契約された方」など）
- [ ] **内容**: ツール名と、それが何をするものか
- [ ] **時期**: いつ渡すか（契約確認後◯日以内など）
- [ ] **方法**: どうやって渡すか（LINEでURL送付など）
- [ ] サポートの有無（使い方の説明はするのか、渡すだけか）

## 4. ★ ステマ規制への対応（必須）

スナ経由の契約で**紹介報酬が発生する場合、ステマ規制（景品表示法）の対象**になります。
2023年10月から、広告であることを隠した表示は違反です。

### 対応は簡単で、しかもスナのキャラと相性が最高です

```
先に言うときます。

僕、これ紹介したら紹介料もらえます。
隠しても後でバレるだけなんで、言うときます。

その上で紹介してるのは、
自分が実際に使って結果が出たからです。

紹介料が出るからといって、
合わん人に「合いますよ」と言うことはしません。
それやったら僕の5年間が無駄になるんで。
```

**隠すとリスクですが、先に言うと信頼になります。**
スナの既存の語り（「無料相談と言うといて後から売られるのが一番嫌い」）と同じ思想なので、
むしろ一貫性が増します。

### 金額は書きません（広告主側との関係上、公開不可）

**ステマ規制が求めているのは「広告であること」が分かることであって、対価の額ではありません。**
金額を伏せても、下の文面で要件は満たします。

```
僕、これ紹介して契約になったら、紹介料もらいます。

なんぼかは、契約上言えません。
そこも「書けん部分」のひとつです。

ただ、もらう立場やということは言うときます。
隠しても後でバレるだけなんで。
```

### ★ 伏せたほうが、実は強い

「なんぼかは契約上言えません」は、7ステップ資料の
**「クライアントとの契約上、手順は書けません」と完全に同じ論法**です。

| 場面 | 言っていること |
|---|---|
| 7ステップ資料の冒頭 | 手順は契約上書けん |
| 𝕏記事の末尾 | その先は契約上書けん |
| **6通目の紹介料** | **なんぼかは契約上言えん** |

**3箇所で同じ姿勢を通すことになります。**
読者に残るのは「出し惜しみする人」ではなく、**「どこでも契約を守る人」**という像です。

契約を守る人にしか、60万円は預けられません。
**金額を書くより、こちらのほうが効きます。**

何も言わずに飛ばすと、読者は「あ、そういう感じか」となります。

飛ばす前に、必ず一言入れてください（原稿は `09` 5通目に反映済み）。

```

僕はああいう書き方はせんのですけど、

```

**先に言っておけば、トーンのギャップが「スナの誠実さ」に変換されます。**
言わなければ、ただのギャップとして残ります。

## 6. LINEの通数への影響

ステップが5通→6通になるので、無料枠の計算が変わります。

| ステップ本数 | 無料枠200通でカバーできる人数 |
|---|---|
| 5通 | 40人 |
| **6通** | **33人** |

目標が月40〜60人なので、**ライトプラン（5,000円/月）への切り替えは早まります。**
運用ルールを更新: **累計登録が25人を超えたら切り替える。**

## 7. 経済性（🔒 社内限り・外部公開不可）

> **⚠️ 以下の金額は広告主側との関係上、非公開情報です。**
> 𝕏・LINE・note・特典ページなど、**読者の目に触れる場所には一切書かないでください。**
> 運用の判断材料としてのみ使います。

### 1件の契約に、LINE登録が何人必要か（紹介料 1件10万円で試算）

各段の転換率は**まだ実測がないので目安**です。実測でベースラインを作る前提で読んでください。

| LP遷移 | Zoom申込 | 成約 | 1件あたり必要なLINE登録 |
|---|---|---|---|
| 30% | 20% | 10% | 167人（悲観） |
| **40%** | **20〜30%** | **10〜20%** | **42〜125人（現実的な幅）** |
| 50% | 30% | 20% | 33人（楽観） |

**中央あたりを取ると「LINE登録80人で1件」**と見ておくのが妥当です。

### 月次の姿

| 月間LINE登録 | 想定契約数 | 紹介料収入 | LINE費用を引いた残り |
|---|---|---|---|
| 40人（週10） | 月0.5件 | 5万円 | 4.5万円 |
| 60人（週15） | 月0.75件 | 7.5万円 | 7万円 |
| **100人（週25）** | **月1.2件** | **12万円** | **11.5万円** |
| 150人（週37） | 月1.9件 | 19万円 | 18.5万円 |

> **ライトプラン5,000円/月は、1件成約すれば20ヶ月分です。** ここを渋る理由は一切ありません。

### 目標の見直し

これまで「LINE登録 週10〜15人」を目標に置いていましたが、
その水準だと **契約は月0.5〜0.75件**。つまり**1〜2ヶ月に1件**のペースです。

フォロワー200からいきなり週25登録は届かないので、段階を置きます。

| 期 | 目標 | 内容 |
|---|---|---|
| **1〜3ヶ月目** | **契約1件を出す** | 月次で安定させようとしない。**まず1件通す**。ここでファネルの実数字が取れる |
| 4〜6ヶ月目 | 月1件 | 週20〜25登録。フォロワー800〜1,000が前提 |
| 7ヶ月目〜 | 月2件以上 | 転換率の改善フェーズ。ここで初めて率をいじる |

## 8. ★ LP完結による最大の問題 ── ファネル後半が見えません

Zoomの申込・実施がLP側で完結するため、**スナが持てる数字は前半だけ**になります。

| 段 | 取れるか | 取り方 |
|---|---|---|
| LINE登録数 | ✅ | プロライン |
| LP遷移クリック数 | ✅ | プロラインのURLクリック計測 |
| **Zoom申込数** | ❌ | LP側の数字 |
| **Zoom参加数** | ❌ | LP側の数字 |
| **断られた理由** | ❌ | 実施者しか知らない |
| 契約数 | ✅ | ツール特典の申告 |

> **LP遷移から契約までが、完全なブラックボックスになります。**
> 数字が取れないと、どこを直せばいいか永遠に分かりません。
> 月1件ペースの規模では、これは致命的です。

### 対策：「申し込んだら教えてください」の動機を作る

ただ「教えてください」では誰も教えてくれません。**教える理由**が要ります。

```
Zoom申し込んだら、一言だけLINEで教えてください。

当日どう使ったらええか、僕から一言だけ送ります。
限られた時間なんで、何を聞くか決めて入ったほうが絶対に得なんで。
```

これ1つで、次の4つが同時に手に入ります。

| # | 効果 |
|---|---|
| 1 | **Zoom申込数が計測できる**（ブラックボックスに穴が開く） |
| 2 | **スナとの接点が保たれる** ← 実施者が別人であることへの対策 |
| 3 | 使えなくなった「事前質問欄」の代わりになる |
| 4 | **翌日フォローができる → 断り理由が取れる**（改善のループが回る） |

**4が一番大きいです。** 母数が少ないうちは、断られた理由を1件ずつ拾うしか改善手段がありません。

## 9. ツール特典の受け渡し導線（確定）

```
教材を契約
   ↓
スナのLINEに「契約しました」と連絡  ← ここが申告ポイント
   ↓
スナが確認
   ↓
特典サイトのURLを個別に送付  ← 一斉配信しない
   ↓
サイト上で使い方の説明 + ツールのダウンロード
```

### 特典サイトの作り方

**プロラインフリーの「コンテンツページ」で作れます**（無料・無制限）。
別途サーバーを借りる必要はありません。

### ⚠️ URLの扱い

コンテンツページは**URLを知っていれば誰でも見られます。**

- [ ] URLは**必ず個別に送る**。一斉配信・LINEのリッチメニューには置かない
- [ ] ページ内に「転載・再配布禁止」を明記
- [ ] 漏れた形跡があれば、**ページを作り直してURLを変える**（作り直しは無料）
- [ ] ツール本体のDLリンクも、そのページ内に置く（外部に直リンクを置かない）

### 特典ページに書くこと

| 項目 | 内容 |
|---|---|
| 冒頭 | 契約への一言（売り切りでなく、ここから始まるという姿勢） |
| ツール① | ASP案件抽出ツール ─ 何をするものか / DL / 使い方 |
| ツール② | Google広告 一括出稿・更新ツール ─ 同上 |
| 注意書き | 転載禁止 / 動作環境 / **サポートの範囲（下記）** |
| 導線 | 困ったときの連絡先（スナのLINE） |

### サポート範囲の明記（確定）

対応するのは **ツールの操作説明とエラー対応のみ**。PPCの運用相談は受けません。
そのまま使える文面がこちらです。

```
【サポートの範囲】

このツールについて、僕が対応できるのは2つだけです。

　・操作の説明
　・エラーが出たときの対応

PPCの運用相談そのものは受けてません。
そこは教材とZoomの領域なんで。

あと、たいがいのことは
ClaudeなりGeminiなりに聞いたら解決します。

エラー文をそのまま貼って「これ何？」で、だいたい返ってきます。

意地悪で言うてるんやなくて、
AIに聞く癖がついたほうが、この先ぜんぶ速なるからです。
```

> **最後の2行が効きます。** 「AIに聞いてください」は普通なら突き放しですが、
> **「AIをムチ打つ」がこのアカウントの世界観の中心**なので、
> スナが言うと**教育**になります。線引きが、そのまま思想の表明になる。
>
> これを書かないと、ツールの使い方からPPCの運用相談まで無制限に来ます。
> **1日30分の運用が崩壊します。**
