> **状態: 記事本文の取得ができていないため、構造とテンプレートのみ。**
> 本文をいただき次第、記事の言葉を拾って具体化します。

---

## 1. 橋の設計思想

### 1-1. 3つの階段は「同じ構造」で揃える

```
𝕏記事        … なぜ(Why) と 何が起きているか(What) を出し切る → How の入口で止める
   ↓
7ステップ資料 … 全体の地図(What) を出し切る → How は契約上出せないと明示
   ↓
無料Zoom      … あなたの場合の How を一緒に見る
```

**3段とも「Whatは出す / Howは出さない」で統一されています。**
だから読者は毎回「なるほど、でも自分にはまだできない」と感じ、自然に次の段へ進みます。

逆に言うと、**どこか1段で "Howを出しすぎる" と、そこで階段が終わります。**
記事で解けた気になった人は、LINEに登録しません。

> ⚠️ **これが記事本文を見せていただきたい最大の理由です。**
> 記事がすでに手順まで踏み込んでいると、7ステップ資料の価値が消えます。
> その場合は、資料側の切り口を変える必要があります。

### 1-2. 記事末尾のCTAで、やってはいけないこと

| ❌ | なぜダメか |
|---|---|
| 「続きはLINEで」 | 出し惜しみに見える。ペルソナ（キラキラを疑う人）が一番嫌う型 |
| 「無料プレゼント配布中！」 | 情報商材の定型文。スナのトーンから外れる |
| 「今だけ限定」 | 景表法リスク。かつ煽りに見える |
| Zoomの存在を完全に隠す | ステップ5通目で驚かれる。「やっぱりそういうことか」になる |
| Zoomを前面に出す | 記事の直後にいきなり商談の匂いがして、登録ハードルが上がる |

### 1-3. 正解の型

> **「もっと知りたい人へ」ではなく、「ここで止まった人へ」。**

読者が記事を読んで**実際に感じるであろう引っかかりを、こちらから先に名指しする。**
名指しされた人は「この人は分かってる」と思い、リンクを押します。

Zoomについては **一言だけ触れる。** 隠さない、押さない。
スナのトンマナ（先に正直に言う）と一貫させます。

## 4. 固定ポスト（記事へ誘導するポスト）の扱い

固定ポストは**記事へのリンクのまま**にしてください。LINEに直行させません。

```
固定ポスト → 𝕏記事 → LINE登録 → ステップ5通 → Zoom
```

理由：**記事を読ませてからのほうが、LINE登録の質が上がります。**
記事で「この人の言うことは分かる」となった人だけが登録するので、
ステップ配信の開封率もZoom申込率も上がります。

ただし、記事を読まずに直接LINEに来たい人のために、
**プロフィールのリンク欄には LINE登録URL（流入経路：`X_プロフリンク`）** を置きます。
2経路を分けておけば、どちらが効いているか後から数字で分かります。

| 置き場所 | リンク先 | 流入経路タグ |
|---|---|---|
| 固定ポスト | **𝕏記事** | 記事末尾で `X_記事` |
| プロフィールのリンク欄 | **LINE登録** | `X_プロフリンク` |
| 通常ポストのツリー最終 | LINE登録 | `X_通常ポスト` |
