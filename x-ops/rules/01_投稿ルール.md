# 2-1 配信ルール（本体・確定版）

> 迷ったらここを見る。1人運用なので、**判断を減らすことが最大の時短**。

## 0. 1日の配信量と時間配分（確定）

### 目標量

| 種別 | 本数/日 | 作り方 |
|---|---|---|
| 通常ポスト | 3〜5 | **週1回まとめて生成・予約**。平日は書かない |
| 交流（引用リポスト／リプライ） | 20〜30 | その場で。1本30〜60秒 |
| 𝕏記事の引用リポスト | 10〜20 | **タイトル中心に見て1〜2行**。1本20〜30秒 |

### 平日30分の内訳（毎日）

| 時間 | やること |
|---|---|
| 2分 | 予約投稿の確認（前夜に書いたものを朝の頭で読み直す＝時間差レビュー） |
| 15分 | 交流 20〜30本（リプライ8〜12 + 引用リポスト12〜18） |
| 8分 | 𝕏記事の引用リポスト 10〜20本（3型ローテーション） |
| 3分 | 明日の記事ネタをブックマークしておく |
| 2分 | 前日ポストの数値をDB-Aに記録（投稿URL＋インプ＋エンゲージのみ） |

**これで30分に収まります。** 前回「60〜100分かかる」とお伝えしたのは、
記事引用を「読んでから書く」前提で見積もったためでした。
タイトルベースで1〜2行なら1本20〜30秒なので、指定量のまま30分に入ります。

> ただし1点だけ条件があります。**AI・Google広告の仕様変更を扱う記事のときは、
> リード文の2〜3行だけ5秒見てください。** タイトルと中身が食い違う記事を断定口調で
> 引用すると、この規模では致命的に信頼を落とします（→ 04_交流ルール 3章）。

### 週末のまとめ作業（60〜90分 / 週1回）

| 時間 | やること |
|---|---|
| 45分 | 翌週の通常ポスト **21〜35本を一括生成 → 予約投入** |
| 20分 | DB-Eで週次の数値をふりかえり、翌週の型を決める |
| 15分 | ネタ帳（DB-B）の補充 |

## 1. 配信時間帯（確定）

| 枠 | 時間 | 種類 | 狙い |
|---|---|---|---|
| 朝 | **06:00** | マインド・鼓舞（柱①） | 出勤前の絶望感に寄り添い「AIを使えば未来は変わる」と示す。通勤中のスマホを止める |
| 昼 | **12:00過ぎ** | 共感・効率化（柱②） | 外回り・休憩中のしんどさに共感。隙間でAIをどう動かすかの現場の知恵 |
| 休日 | **15:30**（休日のみ） | ライフスタイル（柱③） | 稼ぐ目的が家族であることを再認識させ、人間味でファン化を加速 |
| 夜 | **20:00** | 実績・ロジック（柱④） | 収益・AIへの指示出し・戦略。「この人は本物だ」という権威性 |

- 交流（引用リポスト）は **朝の通勤時間帯と夜21〜23時**に固める。相手がオンラインの時間に当てる。

## 2. 本文のルール

| 項目 | ルール |
|---|---|
| 文字数 | **140〜200字**。上限200字を超えない（ベンチマーク分析の結論） |
| 冒頭1行（フック） | 最重要。下記5型のいずれかを必ず使う |
| 改行 | 2〜3行ごとに空行。1行は25字程度まで |
| 箇条書き | 複数要素を述べるときは必ずリスト化（konsuke_money型が高エンゲージ） |
| 一人称 | 僕 / 俺（文脈で使い分け。「私」は使わない） |
| 文体 | 丁寧語ベース + 関西弁を崩さない（「ですね」「ます」の後に「〜やわ」「知らんけど」） |
| 感嘆符 | 「！」は多用しない。淡々と語る |
| 絵文字 | 装飾目的では使わない。使うなら1投稿1個まで |
| ハッシュタグ | 末尾に **2〜3個**（#副業 #AI副業 #会社員副業 が基本セット） |

### フック5型（1行目に必ずどれかを使う）

| 型 | 例 |
|---|---|
| 疑問形 | 「え、まだ営業のギャラだけで生きてるん？」 |
| 数字 | 「手取り20万サラリーマンが毎日2時間で月5万稼いでた理由」 |
| 常識破壊 | 「足で稼げ、という上司の言葉は今や凶器ですね。」 |
| 問題提示 | 「副業を続けてる人が全員ぶつかる壁がある。」 |
| 反語的疑問 | 「5時から活動してるアクティブな人さすがにいないよね？」 |

### バズポストの5段構造

1. フック（疑問形 or 数字）
2. 理由（なぜなら〜）
3. 具体例（数字入り）
4. 根拠（自分の実体験・実測値）
5. CTA（下記3パターンから1つ）

### CTAの3パターン（毎回どれかを入れる）

- **質問形**: 「あなたはどの副業が一番ハマった？返信してみて」
- **共感形**: 「同じく毎日2時間だけの人、一緒に頑張ろ」
- **行動形**: 「固定欄見て、まずやってみて」

## 3. 画像

| 項目 | ルール |
|---|---|
| 方針 | **画像は必須ではない**。ベンチマーク上、バズ投稿の60〜80%は画像なし |
| 使用比率 | 週の投稿の **30%以内**。残りはテキストのみで出す |
| 使うとき | ブランディング（実績スクショ・図解）に限る。インプ稼ぎ目的では使わない |
| altテキスト | 入れる |
| 権利 | 実績スクショは金額以外（顧客名・案件名・ASP名）をマスクする |

## 4. スレッド（ツリー投稿）

- 全体の **30%** をツリーにする。主に**朝または夜**に配置。
- 残り70%は1ポスト完結。主に昼・休日午後。

| 枚目 | 役割 |
|---|---|
| 1枚目（親） | 【Hook】強い言葉で指を止め、共感または違和感を与える |
| 2枚目（リプ） | 【Logic & Detail】具体的なAI活用術、営業現場でのエピソード |
| 3枚目（リプ） | 【Closure】家族愛・ストイックさという信念を語り、余韻を残す |

## 5. URL・導線

| 項目 | ルール |
|---|---|
| 本文へのURL | **入れない**。表示が落ちる。リンクは固定ポスト or ツリー最終ポストに置く |
| 導線 | 𝕏 → note / 公式LINE → 無料Zoom → 教材 |
| CTAの置き場所 | 通常ポストは「固定欄見て」まで。直接のセールスは打たない |
| 計測 | リンクにUTMを付ける `utm_source=x&utm_medium=social&utm_campaign=【施策名】` |

## 6. 予約投稿

- 通常ポストは**原則すべて予約**。当日その場で書かない（30分に収める前提）。

> **⚠️ 𝕏公式の予約投稿はCSV一括投入ができません。** 21〜35本を1本ずつ入れると、
> 1本30秒でも15〜20分かかります。Google Driveに既にお持ちの
> **`X予約投稿ツール(ver2.5)`（スプレッドシート）** を使えばこの工程を一括化できます。
> 週末の45分のうち、投入作業を5分に圧縮できるので、そのぶんを本文の質に回せます。
> 使えるか一度確認してみてください。
- 使用ツール: 【要記入：X予約投稿ツール(ver2.5) / SocialDog / その他】
- **災害・大規模事故・著名人の訃報が発生したら、予約を即時停止**（→ 05）。

## 7. 投稿後

- 投稿URLをDB-Aに記録。24時間後にインプ・エンゲージ・プロフクリックを記録。
- 誤字・事実誤認は**編集ではなく削除→再投稿**。削除理由をDB-Aに残す。
