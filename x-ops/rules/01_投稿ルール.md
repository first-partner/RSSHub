# 2-1 投稿ルール（配信ルール本体）

> 迷ったらここを見る。ここに書いていないことは「やってよい」ではなく「承認者に聞く」。

## 1. 配信量と頻度

| 項目 | ルール |
|---|---|
| 投稿本数 | 1日 【要記入】本（推奨: 立ち上げ期 1〜3本 / 拡大期 3〜5本） |
| 稼働曜日 | 【要記入】（例: 月〜金。土日は予約投稿のみ） |
| 予約投稿の締切 | 投稿予定の【要記入】時間前までに承認完了 |
| 連投の間隔 | 同一アカウントの連続投稿は最低【要記入】分あける |
| スレッド | 1日1本まで / 上限【要記入】ポスト |

## 2. 配信時間帯

| 枠 | 時間 | 主な用途 |
|---|---|---|
| 朝 | 7:00–9:00 | 通勤時。教育・あるある |
| 昼 | 12:00–13:00 | 休憩時。軽い内容・アンケート |
| 夕 | 17:00–19:00 | 退勤時。ノウハウ・まとめ |
| 夜 | 21:00–23:00 | 滞在時間が長い。長文・スレッド |

- 実績が溜まったらDB-Eで検証し、3ヶ月ごとに時間帯を見直す。
- 【要記入】: 自社のフォロワーの活動時間（𝕏アナリティクスで確認）

## 3. 本文のルール

| 項目 | ルール |
|---|---|
| 文字数 | 通常 【140〜200字】を推奨。長文は改行で区切る |
| 冒頭1行 | **最重要**。「続きを読む」を押させる一行にする。結論・数字・意外性のいずれかを置く |
| 改行 | 2〜3行ごとに1行空ける。1行は最大【25】字程度 |
| 絵文字 | 1投稿あたり【要記入】個まで。装飾目的の乱用は禁止 |
| 記号（■▼✅など） | 箇条書きの頭に限り可 |
| 一人称 | 【要記入】（例: 「私たち」「◯◯（サービス名）」） |
| 敬体/常体 | 【要記入】（原則: です・ます） |
| 数字 | 半角。単位は全角スペースなし |
| 英数字 | 半角。文中の英単語の前後に半角スペース |

## 4. ハッシュタグ

| 項目 | ルール |
|---|---|
| 個数 | 1投稿【0〜2】個。3個以上は表示が落ちるため禁止 |
| 位置 | 本文末尾に改行して置く |
| 常用タグ | 【要記入】 |
| 使用禁止タグ | トレンド便乗タグ（内容と無関係なもの）、公序良俗に反するもの |

## 5. URL・リンク

| 項目 | ルール |
|---|---|
| 本文へのURL | 原則、**単発ポストの本文にはURLを入れない**（表示が落ちるため）。リプライ or スレッド2投稿目に置く |
| 計測 | 外部リンクには必ずUTMパラメータを付与。命名規則: `utm_source=x&utm_medium=social&utm_campaign=【施策名】` |
| 短縮URL | 自社ドメインの短縮のみ可。第三者の短縮サービスは不可 |
| 遷移先の確認 | 投稿前に必ず実機で遷移確認（404・要ログインになっていないか） |

## 6. 画像・動画

| 項目 | ルール |
|---|---|
| 画像枚数 | 1枚（縦長 4:5 推奨） or 4枚。2〜3枚はレイアウトが崩れるため非推奨 |
| 推奨サイズ | 単体 1600×900（16:9）/ 縦長 1080×1350（4:5） |
| 文字サイズ | スマホで読める大きさ（本文相当で最低 32px 相当） |
| 動画 | 尺は【0:15〜0:60】。**字幕必須**（無音再生前提） |
| alt テキスト | **全画像に必須**（アクセシビリティ / 検索性） |
| 権利確認 | 素材の使用許諾を確認しDB-Aの「権利確認」にチェック。**未チェックの投稿は承認不可** |
| 人物写り込み | 社外の人物が写る場合は書面の許諾必須 |

## 7. 投稿の種類ごとの扱い

| 種別 | ルール |
|---|---|
| 単発ポスト | 通常運用 |
| スレッド | 1本目で結論、最終ポストにCTA（フォロー / リンク） |
| 引用ポスト | 引用元の意図を歪めない。批判的引用は原則禁止 |
| リポスト | 自社・パートナー・顧客の言及のみ。**個人の投稿の無断転載は禁止** |
| アンケート | 週【1】回まで。選択肢は4つ、期間は24時間 |
| 予約投稿 | 使用ツール: 【要記入】。災害・重大ニュース発生時は**即時に全予約を停止**（→ 05_承認フローと炎上対応） |

## 8. 投稿後の運用

- 投稿URLをDB-Aの「投稿URL」に貼る。
- 投稿24時間後に数値（インプレッション / エンゲージメント / プロフクリック）をDB-Aに記録。
- 誤字・事実誤認を見つけたら、**編集ではなく削除→再投稿**を原則とする（判断は承認者）。
  - 削除した場合は必ずDB-Aに「削除理由」を残す。
