# 3-2 LINEオファーとステップ配信（確定版）

## 1. オファーの設計思想

ご指定の構造を整理すると、こうなります。

```
全体像（What）を見せる      → 「なるほど、こうやって進めるのか」
   ↓
やり方（How）は出せない      → クライアントとの契約上、開示できない部分がある
   ↓
見ると「できそう」に見える    → 手順が具体的だから
   ↓
でも実際にはノウハウがないとできない
   ↓
その差を埋めるために相談する場が Zoom
```

**この構造自体は正しい設計です。** ただし、扱いを一歩間違えると
「焦らして引っ張っているだけ」に見えて、ペルソナ（キラキラを見ると冷める人）に嫌われます。

分かれ目はひとつだけです。

> **「出せない」ことを、隠して焦らすのか、先に正直に言うのか。**

スナのキャラクター（淡々・誠実・リアリスト）なら、**先に正直に言う一択**です。
そしてこれは、信頼を落とすどころか**最も強い信頼の獲得手段**になります。

## 2. オファーの中身

### タイトル

**「毎日2時間で月120万にした AI×広告の7ステップ」**

### 冒頭に必ず入れる宣言文（★これが命）

> 先に言っておきます。
>
> この資料に、具体的な手順は書いていません。
> クライアントとの契約上、出せない部分があるからです。
>
> 書いてあるのは「全体の地図」です。
> どこを通るかは分かるけど、道の歩き方までは書いていない。
>
> それでも、地図があるのとないのとでは全然違います。
> 僕は5年間、地図を持たずに歩いて、月2万が天井でした。
>
> 知らんけど。

この4行があるかないかで、資料の受け取られ方が180度変わります。
**「出し惜しみしている人」から「約束を守る人」に変わる**からです。

### 7ステップの構成

各ステップで書くこと・書かないことを固定します。

| | 書く（What） | 書かない（How） |
|---|---|---|
| 内容 | 何をやるか / なぜ必要か / どのくらい時間がかかるか / **自分がどこでつまずいたか** | 具体的な設定手順 / 除外KWリスト / 案件名 / ASPの攻略法 / テンプレート |

| # | ステップ | 書く内容の例 | つまずきポイント（← ここが一番効く） |
|---|---|---|---|
| 1 | 市場を選ぶ | どういう軸でジャンルを絞るか（考え方だけ） | 「好きなジャンル」で選んで1年溶かした |
| 2 | 案件を選ぶ | 売れる案件に共通する"観点"（項目名だけ） | 報酬額だけで選んで全部外した |
| 3 | 受け皿を作る | 何のためのページが要るのか（役割の説明） | 作り込みすぎて公開まで3ヶ月かかった |
| 4 | 広告を出す | 出稿までに必要な準備の全体像 | 初日に予算を溶かした |
| 5 | 数字を見る | 何の数字を見て判断するのか（指標名） | 見る数字を間違えて判断が全部逆だった |
| 6 | 止める・伸ばす | 撤退と拡大の判断をどこでするか | 止められずに損失を伸ばした |
| 7 | AIに任せる | どの工程を自動化できるか | 全部任せようとして全部やり直しになった |

> **「つまずきポイント」の欄が、この資料の価値の8割です。**
> 手順は出せなくても、失敗は出せます。そして失敗のほうが、読み手には刺さります。
> ペルソナは「うまくいった話」ではなく「自分と同じところで詰まった人の話」を求めています。

### 分量

A4で7〜10ページ程度。作り込みすぎない。**PDFの完成度より、出す速さを優先**してください。

## 3. LINEステップ配信（5通）

登録直後から7日間。**4通目が最重要**です（後述）。

| 通 | タイミング | 内容 | 狙い |
|---|---|---|---|
| **1** | 登録直後 | 資料お渡し + 自己紹介 + **「全部は出せない」の宣言** | 期待値を先に正しく置く |
| **2** | 翌日 | なぜ営業マンにAI×広告が向いているのか | 「自分にもできそう」を作る（柱②の拡張） |
| **3** | 3日目 | **5年間、月2万が天井だった話** | 失敗の開示。ここで信頼が決まる |
| **4** | 5日目 | **Zoom実施者の紹介** ★最重要 | 当日を初対面にしない（→ 4章） |
| **5** | 7日目 | Zoomの案内 + **位置づけの明示** + 申込 | 期待値のギャップをなくす |

### 5通目に必ず入れる文（★成約率に直結）

> このZoomは「教える場」ではありません。
> あなたの状況を聞いて、どこが引っかかっているかを一緒に見る場です。
>
> それと、先に言っておきます。
> **話を聞いた上で、有料の教材のご案内をします。**
> 合わないと思ったら、その場で断ってもらって大丈夫です。

**「無料相談」と名乗って実質セールスだと、ペルソナは身構えます。**
先に言っておけば、来た人は納得済みで来ます。
**冷やかしは減りますが、来た人の温度は上がります。** 月1件の母数なら、質を上げるほうが効きます。

これは景表法・特商法の観点でも安全側の設計です。

## 4. Zoom実施者の紹介（同席不可の代替策）

### 前提の確認

同席は不可とのことなので、**「信頼の断絶」は緩和はできても解消はできません。**
その前提で、できることを効果の大きい順に並べます。

| # | 施策 | 実行 | 効果 |
|---|---|---|---|
| **1** | **ステップ配信4通目で実施者を紹介する** | 可能 | ★★★ |
| **2** | **Zoom後にスナのLINEからフォローする** | 可能 | ★★★ |
| 3 | 申込フォームに事前質問欄を置き、実施者に渡す | 可能 | ★★ |
| 4 | 𝕏で普段から実施者に言及しておく | 可能 | ★★ |
| 5 | Zoom前日にLINEでリマインド＋一言添える | 可能 | ★ |

### 施策1：紹介コンテンツの書き方

動画が理想ですが、テキスト＋写真でも十分機能します。**スナの言葉で**書くことが条件です。

含めるもの：

1. **なぜ自分がやらないのか**（正直に言う）
   例:「僕は本業が11時間拘束なので、平日の日中に時間が取れません。だから〇〇さんにお願いしています。」
2. **どういう関係なのか**（どこで知り合い、どのくらいの付き合いか）
3. **なぜこの人なのか**（実績ではなく、**自分が信頼している具体的な理由**）
   例:「僕が最初につまずいたとき、答えを教えずに"どこで詰まってる？"って聞いてくれた人です。」
4. **当日どう使えばいいか**
   例:「遠慮なく聞いてください。僕も最初は"こんなこと聞いていいのか"って思ってましたが、聞いた分だけ早かったです。」

> **実績の羅列は逆効果**です。ペルソナは実績で人を信用しません。
> 「この人は自分を舐めないか」を見ています。**関係性のエピソードを1つ**入れてください。

### 施策2：Zoom後のフォロー（★母数が少ない今、最も価値がある）

Zoom翌日に、スナのLINEから一言。

> 「昨日どうでした？ 何か引っかかったとこあります？」

**これは成約のためというより、情報を取るためにやってください。**
月1件しか母数がない状態では、**断られた理由を直接聞かないと永遠に原因が分かりません。**
実施者経由の報告では「検討します」で終わりますが、
スナから聞けば「正直、金額が」「一人でやれる気がしなくて」といった本音が出ます。

聞き出したい3点：
1. 何が一番引っかかったか（金額 / 時間 / 自信 / 信頼）
2. どこまでは納得できたか
3. どうなっていたら「やる」と言えたか

**これを3件貯めた時点で、次に直す場所が確定します。**

### 施策3：申込フォームの事前質問欄

申込時に1問だけ。

> 「今、副業で一番困っていることを1行で教えてください」

これを実施者に渡す。参加者は「準備して来てくれた」と感じますし、
実施者も当日いきなりヒアリングから始めずに済みます。

## 5. 導線の全体像（確定）

```
𝕏（通常ポスト3〜5 + 交流20〜30 + 記事引用10〜20）
   ↓ 固定ポスト
𝕏記事（PPCの入口・現行を流用 / 末尾CTAを Zoom → LINE登録 に差し替え）
   ↓ オファー = 「AI×広告の7ステップ」
LINE公式
   ↓ ステップ配信 5通（7日間）／4通目で実施者を紹介
無料Zoom（相談の場。有料案内があることを事前明示）
   ↓ 翌日：スナのLINEからフォロー ★
教材 60万円
```
