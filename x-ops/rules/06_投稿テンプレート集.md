# 4. 投稿テンプレート集（スナ版）

## 柱① 【常識破壊】根性論への決別（30% / 主に朝06:00 / 週3〜4本）

**構造**: 親ポストで世の中の「当たり前」を否定 → リプで、なぜ非効率か・AIならどう解決するかを淡々と説く。

```
[親] 足で稼げ、という上司の言葉は今や凶器ですね。
    11時間拘束されて身体壊したら終わりやわ。

[リプ] AIにリストアップと下書きを任せれば、移動中に商談の準備が整います。
      根性より仕組み。これが現代の生存戦略ですね。
```

**言い換えの引き出し**: 「100件訪問するより、AIに100通の刺さるメールを作らせる方が成約率は高いですね。」

## 柱② 【営業×AI】スキルの転用術（30% / 主に昼12:00過ぎ / 週4〜5本）

**構造**: 営業マンの「あるある」をAIでハックする → 具体的なプロンプトの考え方と「浮いた時間」の価値。

```
[親] IT音痴の顧客への説明資料、これ作るだけで3時間消えてませんか？
    僕はAIに構成を投げてます。

[リプ] 「5歳児でもわかるように」と指示するだけで、深夜残業がゼロになります。
      浮いた時間で、子供と夕飯が食べられる。美味しいとこ取りでええんです。
```

## 柱③ 【パパの哀愁】共感の醸成（20% / 週末15:30・平日夜 / 週2〜3本）

**構造**: パパとしての孤独 or 家族への愛をポツリと呟く → だからこそ稼ぐことに執着する、という決意。

```
[親] 子供が描いてくれたパパの絵が、全部「寝てる姿」やったときは、
    さすがに死んだ目も潤みましたね。

[リプ] 感謝でオムツは買えんけど、時間はAIで作れる。
      子供が起きてる間に、隣にいられる環境をAIと作ります。明日も淡々とやるわ。
```

## 柱④ 【生存戦略】実績と未来予測（20% / 週半ばの夜・日曜夜 / 週2本）

**構造**: 月120万の裏側にある冷徹な数字 → 「準備している者だけが勝つ」という現実。

```
[親] 給料以外に月10万あるだけで、会社での理不尽に「無の境地」でいられます。
    心の余裕は札束で作るもんですね。

[リプ] AI軍団を組織して1年。今は寝てる間も広告が回ります。
      準備不足は最大の罪。僕は家族を守るために、AIをムチ打ち続けますよ。
```

## 汎用フォーマット

### A. リスト型（konsuke_money型 / バズ率が最も高い）

```
[フック：数字 or 疑問形]

①◯◯◯
②◯◯◯
③◯◯◯

[一言の総括]

[CTA]
#副業 #AI副業 #会社員副業
```

**実例**: 「副業で時間を作る5つの技術。①通勤時間を副業時間に変える ②夜は疲れてても、できる作業だけやる…保存して今日から1つだけ試して。」

### B. ビフォーアフター型（数字で殴る）

```
[過去のダメな自分を1行]

1日5時間 → 月2万（時給133円）
1日2時間 → 月80万（時給1.3万円）

変わったのは2つだけ
①◯◯
②◯◯
```

### C. 問題提示 → 励まし型（kazuma_Freelife型 / 返信が伸びる）

```
副業を続けてる人が全員ぶつかる壁がある。

それは「3〜6ヶ月目の成果出ない期」

[自分がその時期にどうだったか]

[あなたはどう？ 系のCTA]
```

### D. 実績報告型（週1まで）

```
[数字を1行で]

[その裏側にあった地味な事実を2〜3行]

[驕らない締め]
```

> **注意**: 実績報告は週1本まで。連発すると「キラキラ枠」に見えて、
> ペルソナ（キラキラを見ると冷める人）が離れます。

## 使い回しの禁止事項

- 同じ型を3日連続で使わない。
- 同じフレーズ（「感謝でオムツは買えん」等）を週2回以上使わない。
- ベンチマークアカウントの投稿を、語尾だけ変えて使うのは**盗用**。型は真似てよいが、中身は自分の一次情報で埋める。
