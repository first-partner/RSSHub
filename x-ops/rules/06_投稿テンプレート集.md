# 4. 投稿テンプレート集

> 「型」を持つと、投稿の質が担当者の調子に左右されなくなります。DB-Dで集めた良い投稿から型を抽出し、ここに追加していってください。

## 冒頭1行（フック）の型

| 型 | 例 |
|---|---|
| 数字 | 「◯◯を3年やって分かった、たった1つのこと。」 |
| 否定 | 「◯◯は、やらなくていいです。」 |
| 失敗告白 | 「◯万円溶かして学んだ話をします。」 |
| 問いかけ | 「なぜ◯◯は続かないと思いますか?」 |
| 常識の逆 | 「『◯◯すべき』は、半分嘘です。」 |
| 具体的な場面 | 「昨日、お客様にこう言われました。」 |

## 投稿フォーマット

### A. ノウハウ型（保存・フォローを取りにいく）

```
【結論を1行】

理由は3つあります。

① ◯◯◯
② ◯◯◯
③ ◯◯◯

特に②が効きます。理由は【1〜2行】。

明日から試せます。
```

### B. 事例型（信頼を積む）

```
【顧客の状況を1行】

課題:
・◯◯
・◯◯

やったこと:
・◯◯

結果: 【数字】

※お客様の許諾を得て掲載しています
```

### C. 共感型（拡散を取りにいく）

```
【あるあるを1行で言い切る】

わかる人にはわかると思うんですが、
【具体的な情景を2〜3行】

みなさんはどうですか?
```

### D. 告知型（成果に接続）

```
【何が・いつから・誰向けか を1行】

【中身を3行】

詳しくはこちら（リプライにリンク）
```

### E. スレッド型

```
1/ 【結論 + これから何を話すか】
2/ 【前提・背景】
3〜n/ 【本題を1ポスト1論点で】
最後/ 【まとめ + フォロー導線 + リンク】
```

## 使い回しNGの注意

- テンプレートは骨格であって、中身のコピーではない。
- 同じ型を3日連続で使わない。
- 参考アカウントの投稿を、語尾だけ変えて使うのは**盗用**。型は真似てよいが、中身は自社の一次情報で埋めること。
