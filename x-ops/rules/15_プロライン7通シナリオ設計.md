# プロラインの7通シナリオに合わせた再設計

> プロラインの推奨テンプレート（7通・3日間）を確認し、
> **構造は採用、煽りは不採用**として組み直しました。
> コンテンツ（資料）を渡すのは**2通目の1回だけ**です。

---

## 1. プロラインのテンプレを、使う部分と捨てる部分に分ける

### テンプレの中身

| # | タイミング | テンプレの内容 |
|---|---|---|
| 1 | 0分後 | 目的設定をしてコンテンツページへ誘導。[期限＋次プレゼント]も明示 |
| 2 | 1分後 | コンテンツを送信する |
| 3 | 1時間後 | 今後のプレゼントの送信計画 |
| 4 | 1日後 8:30 | 期限終了／**行動しないことで失うメリット**やプレゼントに触れる |
| 5 | 2日後 8:30 | 最終日／受け取り方／**お客様の声**を紹介 |
| 6 | 2日後 20:00 | **残り4時間の通知**／目的と次のプレゼントの再確認 |
| 7 | 2日後 22:00 | **あと2時間**：内容には自信があるのですが、何しろ期限があるものですので‥ |

### ✅ 使う部分（構造）

| 要素 | なぜ使うか |
|---|---|
| **0分／1分／1時間 の3連打** | 登録直後がいちばん熱い。**この3通で掴めなければ後は読まれません** |
| **1時間後に「配信計画」を送る** | 何がいつ来るか分かると、次の開封率が上がります |
| **1通あたり350字以下** | スマホで1画面に収まる。**これは守ります** |
| **7通で終わり、次のシナリオへ渡す** | ダラダラ続けない。区切りがある |

### ❌ 捨てる部分（煽り）

| テンプレの要素 | なぜ捨てるか |
|---|---|
| 「期限終了」「行動しないことで失う」 | 損失回避の煽り。**ペルソナが最も冷める型** |
| 「残り4時間」「あと2時間」 | カウントダウン。`db/F_NGワード辞書.csv` に登録済みのNG |
| 「何しろ期限があるものですので‥」 | 三点リーダーの含み。スナの語り口ではない |
| 「お客様の声を紹介」 | 受講生の実績は**許諾なしに出せません**（`03_NG禁止事項` A項） |

> ⚠️ **最大の理由はこれです。**
> 6通目でLPについて「**『今だけ』とか『無料プレゼント』とか書いてあります。僕はああいう書き方はせんのですけど**」と書いています。
>
> **自分のステップが「残り4時間」を送っていたら、この一文が嘘になります。**
> 一箇所の嘘が、資料も含めた全体を疑わせます。

## 2. 「期限を作らない」こと自体を、差別化に使う

同じジャンルの発信者は、ほぼ全員がこのテンプレ通りに期限を作ります。
**だからこそ、作らないほうが際立ちます。**

3通目に、この2行を入れました。

```
あと、期限は作りません。
急かされて決めるようなもんやないと思ってます。
```

**60万円の商材で「急がなくていい」と言う人は、ほぼいません。**
ペルソナ（キラキラを疑う人）にとって、これは強い信号になります。

> ※ Zoomの枠が実際に限られている場合、それは事実なので伝えて構いません。
> ただし「残り◯枠！」ではなく「埋まってたら次は◯週間後です」程度に留めてください。

|---|---|---|---|
| 1 | **0分後** | 挨拶＋「全部は書けん」宣言＋資料の予告 | 253字 |
| 2 | **1分後** | **資料を渡す**（コンテンツ送信はここ1回のみ） | 138字 |
| 3 | **1時間後** | 配信計画の予告＋「期限は作らない」宣言 | 216字 |
| 4 | **翌日 20:00** | なんで営業マンがこれに向いてるのか | 265字 |
| 5 | **3日目 20:00** | 5年間なにを間違えてたか＋実績の推移 | 298字 |
| 6 | **5日目 20:00** | 実施者の紹介＋LP案内＋「申し込んだら教えて」 | 299字 |

| → | 8日目 | **次のシナリオへ移動** | ─ |

**全通350字以下**（改行を除く実文字数）。

### テンプレとの違い

| | テンプレ | この設計 |
|---|---|---|
| 期間 | 3日間 | **8日間** |
| 動力 | 期限による圧 | **1通ごとに違う「読む理由」** |
| 4〜7通目 | 期限のリマインド×4 | 教育→教育→導線→差別化 |
| 送るもの | プレゼント複数 | **資料1つだけ**（2通目） |

> **なぜ3日ではなく8日か。**
> 60万円の商材で、3日は短すぎます。ただしLINEの役割は「LPに行かせる」までなので、
> 6通目（5日目）でLPを出し、7通目で最後の一押しをする形にしました。
> **8日で決まらない人は、次のシナリオで拾います。**

## 5. 「次のシナリオ」の設計

7通目のあと、プロラインは次のシナリオへ移動します。**行き先を3つに分けてください。**

```
                    ┌─ タグ「Zoom申込」あり  → ② 申込者シナリオ
7通完了 ─ 分岐 ─────┤
                    └─ タグなし              → ① 通常配信シナリオ

                       タグ「契約」あり       → ③ 特典受け渡し（手動）
```

### ① 通常配信シナリオ（申し込まなかった人）

**週1回まで。** それ以上送ると解除されます。

| 送るもの | 中身 |
|---|---|
| 𝕏で反応が良かった投稿の再編集 | 新規に書かない。**𝕏の資産を回す** |
| 資料に書かなかった失敗談 | 1本ずつ小出しに |
| 忘れた頃のLP再案内 | **月1回まで。** 毎回入れると売り込みに見える |

> **目的は「忘れられないこと」だけ**です。売り込みではありません。
> 半年後に「そういえば」で申し込む人が、実際にいます。

### ② 申込者シナリオ（Zoom申込のタグがついた人）

| # | タイミング | 内容 |
|---|---|---|
| 1 | 申告直後 | お礼＋**当日どう使えばいいかのアドバイス**（3通目で約束した分） |
| 2 | Zoom前日 | リマインド＋一言 |
| 3 | **Zoom翌日** | **「昨日どうでした？」** ← ★断り理由の回収。最重要 |

3通目の内容は `09_LINE構築手順` の「番外｜Zoom翌日フォロー」を使ってください。

### ③ 契約者（手動対応）

「契約しました」の連絡 → 確認 → 特典ページのURLを**個別に**送付。
（`13_体験談3点の翻訳とツール特典` 9章）

## 6. 6通設計からの変更点

前の版（`09_LINE構築手順` 4章）は6通・8日でした。**内容は同じで、構成だけ変わります。**

| 前の6通 | 新しい7通 |
|---|---|
| 1通目に資料URLを同梱 | **1通目（予告）と2通目（送信）に分割** ← テンプレの構造 |
| ─ | **3通目に配信計画を追加** ← 開封率が上がる |
| 2通目 営業マン論 | 4通目（内容は同じ・350字に圧縮） |
| 3通目 5年間月2万 | 5通目（実績の推移を追加） |
| 4通目 LP案内 ／ 5通目 実施者紹介 | **6通目に統合** |
| 6通目 ツール＋紹介料 | 7通目（内容は同じ） |

> **`09_LINE構築手順` 4章の6通版は、こちらで置き換えてください。**
> 内容は失われていません。1通あたりが短くなり、テンプレの構造に乗っただけです。
